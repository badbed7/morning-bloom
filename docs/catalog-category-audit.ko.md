# 도감 분류·이미지 대조 및 수정 · 2026-11-03

확인 기준 v0.8.12 / `3c75e40`, 수정 버전 v0.8.13.

## 발견한 분류 불일치

| 상위 분류 | 항목 | 기존 표시 | 수정 표시 | 원인 |
| --- | --- | --- | --- | --- |
| 정원 | 저녁 라벤더 정원 (`lavender`) | 일반 라벤더 식물·토분 | 실제 적용 정원의 배경 타일 | 식물 `lavender`와 정원 `lavender`의 ID 중복을 분류 없이 조회 |
| 화분 | 로즈 리본 (`rose`) | 장미 식물·토분 | 실제 적용 로즈 화분 스킨 | 식물 `rose`와 화분 `rose`의 ID 중복을 분류 없이 조회 |

식물의 라벤더·장미는 해당 식물 이미지를 그대로 사용한다. 기존 ID는 저장·가챠 이력·소유권에 사용하므로 바꾸지 않는다.

## 조사 범위

- 식물 22종 / 정원 83종 / 화분 45종, 도감 150종의 분류·ID·이름과 실제 미리보기를 대조했다.
- 150종 전체 미리보기를 분류별로 렌더링해 다른 상위 분류의 이미지가 남지 않았는지 확인했다.
- 상점 씨앗·정원·화분 선택, 가챠 이력·결과, 정원·바탕화면 꽃 렌더링의 조회 경로도 검색했다. 이들은 이미 분류별 정의를 선택하고 있어 동일한 분류 누락을 발견하지 않았다.
- 이번 점검은 상위 분류와 항목·이미지의 연결 검수다. 모든 벡터 디자인을 원본 시트와 픽셀 단위로 동일하게 만드는 아트 재제작은 포함하지 않는다.

## 수정

- 도감 항목에 `plant / garden / pot` 분류를 명시했다. ID가 어느 사전에 존재하는지 순서대로 추정하는 렌더 분기를 제거했다.
- 그림과 등급을 항목의 명시적 분류로 조회한다. 캐시 식별에도 분류가 포함되어 같은 ID가 다른 분류의 결과를 재사용하지 않는다.
- 항목 생성 시 분류·ID·이름이 같은 실제 정의를 가리키는지 검증하고, 알 수 없는 항목을 임의의 다른 분류로 그리지 않는다.
- 저장 schema·ID·소유권·확률·가격은 변경하지 않는다.

## 검증

- 수정 전 정원 라벤더와 화분 로즈의 식물 렌더 호출 및 이미지 중복을 회귀 검사로 재현했다.
- 신규 검사 6개: 정원 83종에 식물 렌더 금지, 화분 45종에 개화 식물 렌더 금지, 식물 22종의 품종 정의 연결, 중복 ID 양쪽 캐시 순서, 150종 분류·이름·정체성 대조, 잘못된 분류·항목 거부.
- 배포 시작 검사에서도 150종을 전부 렌더하고 라벤더·로즈의 분류 간 이미지가 다른지 확인한다.
- 기존 저장·가챠·UI·업데이터 검사와 EXE/Python-BAT 패키징·실행 검사를 통과한 뒤 게시한다.
