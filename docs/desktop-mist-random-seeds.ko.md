# 분무·바탕화면 정원·랜덤 씨앗 변경 기록

2026-09-17 · 구현 기준: v0.4.1 main에서 확장, 저장 스키마 v8

## 적용한 기획

- 비료 보상 간격 180초, 새 재고 상한 5개. 기존 초과분은 최대 5개의 예비 재고로 보존하고 사용 시 자동 보충.
- 분무에만 3회 클릭 미니게임 적용. 첫 물주기는 변경하지 않음.
- 정원 꽃을 우클릭해 Windows 데스크톱에 부착. 같은 꽃의 보관·생산 기록을 유지하고 중복 보상을 하지 않음.
- 설정의 별도 바탕화면 불투명도 10~100%, 위치 저장, 드래그 이동, 우클릭 복귀, 전체 복귀.
- 햇빛은 꽃 중심 반경 88 논리 픽셀의 보이지 않는 원 안에 분산. `r=R*sqrt(U)` 면적 균등 샘플링 후 클릭 영역 간격을 확보. 토큰 ID 기반 난수로 일반 갱신 때 위치가 흔들리지 않음.
- 랜덤 씨앗 20G. 고대 0.1%, 나머지 3종 각 33.3%. 구매 결과 저장, 개화 전 UI의 이름·시간·판매가 숨김.
- 고대 꽃 기본 500G, 분무 보너스 포함 550G, 성장 48시간. 그림은 기존 벡터 아트 체계로 확장.

20G는 일반 씨앗 가격 8/20/35G를 기준으로 정한 초기 밸런스 값이다. 고대 발견은 구매 시 한 번 결정되며 실제 골드는 성장·수확 후 꽃 판매로 받는다. 유료 결제·현금 보상과 연결하지 않는다.

## 오류 수정

비료 게임의 시작 버튼과 멈추기 버튼을 교체하면서 포커스를 이동하던 구조를 단일 버튼으로 바꿨다. 정상 입력까지 OS 더블클릭 시간만큼 막던 제한을 없애고 실제 더블클릭 이벤트만 필터링한다. 시작 직후 50ms 시점의 키 입력과 다음 입력이 각각 한 라운드씩 반영되는 회귀 테스트를 추가했다. 사용자 환경의 원래 증상을 직접 재현한 것과 동일하다고 단정하지 않으며, 확인한 입력 지연 경로를 수정한 것이다.

분무는 300ms 물방울 애니메이션을 3회 마친 뒤 기존 care 트랜잭션으로 저장한다. 효과는 완료 시 한 번만 적용한다. 중간 취소, 이전 창의 늦은 완료 신호, 다른 화분·개발자 정원으로의 전환, 저장 실패를 검증한다.

## Windows 구현 경계

`desktop_host.py`가 ctypes로 Explorer의 데스크톱 아이콘 뷰를 찾아 꽃 HWND를 자식으로 붙인다. `WS_CHILD`를 설정하고 `WS_POPUP`을 해제한다. 바탕화면 위젯은 일반 앱 뒤에 위치하며, 배경 파일을 바꾸거나 Explorer를 재시작하거나 전역 입력 hook을 설치하지 않는다. 클릭 가능한 꽃·햇빛 영역 이외에는 투명 배경이 마우스를 막지 않도록 창 마스크를 제한한다.

다른 프로세스 창에 붙일 때의 DPI 위험을 피하기 위해 부착 전 DPI context를 확인한다. 호환되지 않으면 정원을 보존하고 오류를 안내한다. 모니터 좌표는 음수 원점을 포함하는 Windows 화면 픽셀로 저장한다. 일반 정원과 개발자 정원의 바탕화면 창도 모드 전환 시 해제·재구성한다.

Explorer 창 클래스는 안정적인 공개 API 계약이 아니다. 현재 머신의 실제 네이티브 부착은 테스트했지만, 모든 Windows 셸·혼합 배율·MSIX 환경의 호환을 보장하지 않는다. 실패 시 일반 최상위 창으로 대체하지 않는다. 이미지 배경에 꽃을 굽는 정적 배경화면 방식이 아니라 상호작용 가능한 Windows 데스크톱 계층 방식이다.

## 저장 보존

v7 원문은 전용 마이그레이션 백업으로 보존한다. v8에는 예비 비료·랜덤 씨앗 결과·미공개 재배 ID·바탕화면 배치·독립 불투명도를 추가한다. 꽃·재화·규칙·스킨·기존 창 설정은 유지한다. 손상·미래 스키마 파일 보호도 유지한다. 현재 사용자 저장을 수동으로 수정하거나 테스트에 사용하지 않았다.

## 검증 방법

최종 확인: 게임 테스트 131개 통과(네이티브 선택 테스트 1개는 기본 실행에서 제외), 배포 테스트 16개 통과, Windows 네이티브 테스트 1개 별도 통과, 소스 실행 시작 검사 통과. 개발자 정원으로 전환한 뒤 원래 바탕화면 배치가 복원되는 경우도 검증했다. 설치용 EXE/MSIX를 새로 빌드하거나 배포하지는 않았다.

Python 3.11 / PySide6 6.8.3에서 실행:

```powershell
$env:PYTHONPATH = 'python'
$env:QT_QPA_PLATFORM = 'offscreen'
.venv\Scripts\python.exe -m unittest discover -s python/tests -q

$env:PYTHONPATH = 'release'
.venv\Scripts\python.exe -m unittest discover -s release/tests -q

$env:PYTHONPATH = 'python'
.venv\Scripts\python.exe release/game_entry.py --smoke-test
```

실제 Windows 데스크톱 테스트는 별도로 선택 실행한다. 사용자 정원이 아닌 임시 저장을 사용하고 테스트 창을 종료 시 정리한다.

```powershell
$env:PYTHONPATH = 'python'
$env:QT_QPA_PLATFORM = 'windows'
$env:BLOOM_TEST_NATIVE_DESKTOP = '1'
.venv\Scripts\python.exe -m unittest discover -s python/tests -p test_desktop_native.py -v
```

네이티브 테스트는 실제 부모 HWND, 자식/최상위 스타일, 위치 변경, 불투명도 설정, Qt 클릭 이벤트에 의한 햇빛 수집, 복귀 정리를 확인한다. 실제 마우스 포인터로 다른 앱·바탕화면 아이콘과의 상호작용, Explorer 재시작, 복합 모니터·MSIX 설치 후 동작은 별도 수동 검증 대상이다.
