# 레퍼런스 꽃 · 장기 재배 · 민들레 씨앗 여행

지정한 8종은 첨부 레퍼런스의 꽃·잎 형태와 색을 바탕으로 벡터로 그린다. 장미의 겹꽃, 은방울꽃의 종 모양, 토끼풀의 흰 꽃과 세 잎, 데이지의 흰 꽃잎, 튤립의 둥근 꽃봉오리, 해바라기의 갈색 꽃심, 라벤더의 보라색 꽃대, 물망초의 파란 꽃송이를 구분한다. 재배 화면·씨앗 봉투·정원·플로팅은 같은 그림을 사용한다. 기존 별꽃과 고대 꽃도 계속 사용할 수 있다.

주말용 3종도 같은 레퍼런스를 따른다. 팬지는 보라·노랑 꽃잎과 보라색 무늬, 코스모스는 분홍 꽃잎·노란 꽃심·가느다란 잎, 프리지아는 줄기를 따라 모인 노란 꽃과 길쭉한 잎으로 구분한다.

모든 꽃은 첫 물주기 후 성장한다. 추가 돌봄은 기존 선택형 단축 규칙이며, 첫 분무는 기본 판매가의 10%를 더한다. 기존에 심은 꽃의 시간·가격은 저장된 개체 값을 유지한다. 랜덤 씨앗 확률은 기존 별꽃·데이지·튤립 각 33.3%, 고대 꽃 0.1%를 유지한다. 새 꽃은 지정 씨앗으로 구매한다.

팬지·코스모스·프리지아는 각각 2·3·4일 주말용, 해바라기·라벤더·은방울꽃은 5·7·14일 휴가용이다. 이 여섯 꽃은 접속을 종료한 기간을 각 꽃의 전체 성장 시간까지 반영하므로 72시간 오프라인 상한 때문에 재접속을 요구하지 않는다. 다른 꽃·햇빛·비료 대기 계산은 기존 상한을 유지한다. 설정의 **휴가 모드는 모든 꽃의 성장을 정지**하므로 주말·휴가용 재배를 진행하려면 끈다. 긴 공백으로 꽃이 사라지거나 시들지는 않는다.

씨앗 선택은 한 페이지에 아이콘 3개씩 표시하며 좌우 버튼으로 넘긴다. 페이지 전환은 선택만 바꾸고 구매·심기는 별도 버튼으로 확정한다.

## 민들레 씨앗 여행

하단 `씨앗여행`에서 언제든 연다. 첫 꽃 보관 전이나 휴가 모드에서도 플레이하고 보상받을 수 있다. 창은 본체의 불투명도를 따르며 제목을 드래그해 이동한다.

- 전체 진행 게이지는 장면 위에 놓고, 목적지인 빈 화분은 장면 가장 오른쪽에 고정한다.
- `누르고 씨앗 날리기` 버튼, 비행장, 스페이스를 누르고 있는 동안만 씨앗이 이동한다. 여러 입력을 함께 누르면 모두 놓아야 멈춘다.
- 강화 0단계의 기본 거리는 실제 누르기 누적 7,200초다. 컴퓨터 시각 변경과 개발자 `+6시간`, 앱을 닫아 둔 시간은 진행으로 계산하지 않는다.
- 다른 창으로 이동하면 입력을 해제하고 일시정지한다. `계속 날리기`로 이어 하며 진행도는 자동 저장한다.
- 별꽃의 기본 판매 속도 3시간 12G를 기준으로 2시간 가치는 8G다. 씨앗이 화분에 도착하면 8G를 즉시 저장하고 진행도를 0으로 되돌린다.
- 완료 식별자로 같은 도착 보상을 한 번만 지급한다. 저장 실패 시 골드를 되돌리고 100% 진행도를 유지해 같은 결과의 저장을 다시 시도한다.
- 현재 강화 구매 UI는 아직 없으며 저장에는 강화 0단계를 기록한다. 후속 강화는 기본 거리 7,200을 유지하고 입력 시간당 이동 속도만 배수로 높인다.

수치와 가격은 첫 적용값이다. 플레이 기록이나 개인 정보를 외부로 수집하지 않는다.

## 데이지 아이콘과 저장

게임 아이콘은 줄기·화분을 제외한 데이지 꽃머리다. 투명 배경 120px PNG와 16~256px Windows ICO를 제공한다. 소스 실행 창·제목줄·작업 표시줄, 새로 빌드하는 게임 EXE와 런처에 적용한다. BAT 파일 자체의 Windows 파일 아이콘은 변경하지 않는다.

저장은 v12다. v1~v11 저장을 이전하고 민들레 진행도·강화 단계·마지막 지급 ID를 추가한다. v9·v10·v11 원문은 각각 전용 `*.json.vN-migration.bak`에 보존한다. v12 저장은 구버전에서 열 수 없으므로 여러 PC를 사용하는 경우 같은 게임 버전을 사용한다. Google Drive 복원도 같은 검증과 이전을 거친다.

자동 검증은 신규 품종 구매·돌봄·수확·판매, 2·3·4일 재실행 개화 경계와 플로팅 보존, 14일 이상 오프라인·성장 정지, 기존 저장과 클라우드 이전, 작은 창의 씨앗 페이지, 아이콘 투명도, 7,200초 경계·강화 속도·홀드/키보드 입력·일시정지·중복 보상·실패 복원을 포함한다.
