# 현재 가챠 규칙 · 수집 확장

확인일: 2026-11-05. 적용 범위: v0.8.20(저장 v20). 공개 배포 버전은 Releases에서 별도 확인한다. 별도 Draft PR #3의 20칸 씨앗 정원 여행 기획은 현재 60칸 시스템에 적용된 규칙이 아니다.

## 현재 보드·결제

- 일반 보드에서는 뽑기마다 공정한 6면 주사위 2개를 독립적으로 굴리고 합만큼 60칸 순환 보드를 이동한다. 이동 거리는 2~12칸이며 7칸이 가장 자주 나온다. 60번 다음은 1번이다.
- 주사위가 구르는 연출 뒤 실제 눈과 합을 표시하고 민들레 씨가 경로의 각 칸을 따라 부드럽게 떠서 이동한다. 10회 뽑기도 주사위 굴림과 이동을 회차별로 이어서 보여준다.
- 보상은 최종 도착 칸에서 회차당 한 번만 받는다. 통과한 특수 칸은 보상을 지급하지 않는다. 이동 칸 수와 무관하게 1회 비용과 보상 개수는 같다.
- 주사위 결과·도착 칸·보상을 계산해 거래를 저장한 다음 연출한다. 연속 클릭은 새 거래를 만들지 않는다. 연출 건너뛰기·닫기·재실행은 이미 저장한 보상을 다시 지급하거나 취소하지 않는다. 기존 저장의 재화·소유권·이력은 보존하며 주사위와 경로는 연출용 결과로 전달한다. 곁길의 위치와 남은 횟수도 저장한다.
- 1회 햇빛 10개, 10회 햇빛 100개다. 신규 가챠 계정은 무료권 3개를 받는다. 주간 무료권 지급은 없다.
- 요청한 횟수 전체를 무료권으로 낼 수 있으면 무료권을 먼저 쓴다. 부족하면 햇빛으로 전액 결제하고 무료권은 보존한다. 무료권과 햇빛의 혼합 결제는 지원하지 않는다.
- 식물 / 화분 / 정원 / 장미 씨앗 분류를 선택한다. 보상은 기존 식물 8종, 장미 씨앗 7종, 화분 44종, 정원 82종으로 총 141종이다. 장미 씨앗은 중복도 매회 씨앗 1개를 지급하며 상점 구매로 해금되지 않는다. 빨강 장미만 상점에서 50G로 구매한다. 식물은 첫 획득 때 영구 재배 해금과 씨앗 1개를 지급하고 이후 골드 상점에서 씨앗을 살 수 있다. 중복 식물은 교환잎만 받는다. [항목·등급 전수표](collection-items.ko.md)를 참고한다.
- 일반 식물 12종·고대 꽃·민들레와 기본 토분·잔디는 기존 경로를 유지한다. 기존 식물·화분·정원은 등급 내 동일 가중치이고, 장미 씨앗은 [색상별 가중치](rose-varieties.ko.md)를 사용한다. 모든 분류는 보드 진행과 천장을 공유한다. 개별 SSR 확률과 비용 변화는 [구현·경제 검증 기록](issue-resolution-2026-11-03.ko.md)에 공개한다.

## 등급·보장·곁길

- 보장 없는 일반 칸에 도착했을 때의 등급 추첨은 R 70%, SR 25%, SSR 5%다. 현재 위치에서 뽑기 1회를 시작할 때의 확률은 주사위와 특수 칸까지 반영해야 하므로 다를 수 있다. 화면의 `확률 상세`는 36개 주사위 조합을 정확히 합산해 다음 1회의 개별 확률을 표시한다.
- 직전 9회가 연속 R이면 다음 회차는 SR 이상이다. 이때 SR 95%, SSR 5%로 추첨한다.
- 직전 59회에 SSR이 없으면 다음 회차는 SSR이다. SR 이상이면 R 연속 횟수가 초기화되고, SSR이면 SSR 미획득 횟수도 초기화된다.
- 11·26·41번 칸은 SR 이상, 56번 칸은 SSR이다. 보장과 특수 칸이 겹쳐도 보상은 한 개다.
- 11·26·41·56번에 정확히 도착하면 해당 출입구의 **12칸 고등급 전용 보드**로 자동 진입한다. 진입 회차는 일반 보드 도착 보상 1개를 받고, 다음 회차부터 곁길에서 추첨한다. 통과는 진입하지 않는다.
- 곁길에서도 주사위 2개의 합으로 2~12칸 이동한다. 시작은 12번(내부 위치 0)이며 12번 다음은 1번이다. 도착 칸에서만 보상 1개를 받는다. 곁길 안의 11번 등은 다른 출입구로 취급하지 않는다.

| 출입구 | 전용 보드 | SSR 확정 칸 | 그 외 칸 |
|---|---|---|---|
| 11번 | 새싹 곁길 | 6·12번 | SR 95% / SSR 5% |
| 26번 | 이슬 곁길 | 4·8·12번 | SR 95% / SSR 5% |
| 41번 | 꽃망울 곁길 | 3·6·9·12번 | SR 95% / SSR 5% |
| 56번 | 황금 곁길 | 1~12번 전체 | 없음: SSR 100% |

- 각 보드의 보상 풀은 선택한 식물·화분·정원·장미 씨앗 분류에서 R을 제외한다. 황금 곁길은 SSR만 포함한다. 보드 전용 신규 아이템은 추가하지 않으며, 기존 세 분류는 등급 내 동일 확률, 장미는 색상별 가중치를 유지한다. 위 확률은 해당 칸에 도착했을 때의 조건부 확률이며 전체 뽑기의 SSR 확률과 다르다.
- 곁길에서 **2회 추첨 후 즉시 일반 보드의 원래 출입구로 복귀**한다. 복귀 자체로 재추첨·보상을 지급하거나 다시 곁길에 진입하지 않는다. 다음 유료 회차에서 일반 보드 이동을 재개한다.
- 회당 햇빛 10개, 무료권 우선·혼합 결제 불가 규칙은 동일하다. 무료 추가 추첨은 없다. 10회 뽑기는 진입·곁길·복귀를 회차 순서대로 처리하며 총 보상은 10개다. 일반 보드와 곁길은 천장을 공유한다.
- 화면은 실제 진행 중인 60칸/12칸 보드로 전환하며, 민들레 씨가 해당 보드의 경로를 따라 이동한다. 이력에는 보드 이름·도착 칸·보상을 표시한다.
- 저장 v15→v16 이전(과거 규칙): 재화·소유권·기존 이력을 보존한다. 기존 곁길 진행 0~3회는 해당 전용 보드의 시작점에서 남은 횟수를 이어간다. 이전의 일반 보드 위치 표시는 해당 출입구로 맞춰 복귀 지점을 고정한다. 이미 4회 진행한 표시는 종료한다. 이전 원본 백업을 유지하며 Drive 복원도 같은 이전 규칙을 적용한다.
- 이 변경으로 고등급 지급량이 증가한다. 비용과 기존 아이템 등급은 유지하며, 곁길이 더해진 결과는 이전 버전의 일반 5% SSR 확률만으로 설명할 수 없다.

- 저장 v16→v17 이전: 0~1회 진행한 곁길은 현재 위치에서 이어간다. 이미 2~3회 진행한 곁길은 추가 차감·보상 없이 일반 보드의 원래 출입구로 복귀한다. 재화·보유 아이템·천장·이력을 보존하며 로컬 원본 백업과 Drive 복원에도 같은 규칙을 적용한다.

## 로즈 화분 획득 경로

- 로즈 리본은 화분 분류의 SSR 뽑기 전용으로 바꾼다. 상점 미리보기에는 '뽑기 전용'을 표시하고 햇빛 구매 버튼을 비활성화한다. 모델에서도 직접 구매를 거부한다.
- 이미 구매했거나 뽑기로 얻은 로즈의 소유권·장착은 유지한다. 이미 보유한 로즈를 회수하지 않는다.
- 기존 다른 화분·정원의 구매 경로는 유지한다. 신규 배경·화분은 뽑기 전용이다. 기존 v14~v16 저장은 v17으로 이전하고 과거 소유권·가챠 이력을 보존한다.

## 교환잎 비료 상점

- 보상 한 개마다 교환잎 1개, 중복이면 R 1개 / SR 3개 / SSR 10개를 추가한다. 기존 지급량을 유지한다.
- 상점에서 교환잎으로 비료를 구매한다. 가격은 조정 가능한 초깃값으로 **5잎당 비료 1개**를 사용한다. 코드의 `FERTILIZER_LEAF_PRICE` 한 곳에서 정한다.
- 비료 보유 상한은 5개다. 가득 차거나 잎이 부족하면 구매와 차감이 모두 일어나지 않는다. 이전 버전 예비 비료를 추가로 늘리지 않는다.
- 미니게임 보상 대기시간과 구매는 별개다. 구매는 휴가 중에도 가능하지만 사용은 기존 휴가·튜토리얼·재배별 상한 규칙을 따른다.
- 교환잎 차감과 비료 증가는 하나의 저장 행동으로 처리한다. 저장 실패 시 둘 다 복원하고, 성공하면 재실행 뒤 같은 재고를 읽는다.

## 확인 범위

주사위 36조합×시작 60칸의 경로·도착, 경계 순환·통과 보상 없음, 보상 저장 후 연출·자연 완료·건너뛰기·이동 중 닫기·재열기·저장 실패를 자동 검사한다. 로즈 획득 경로와 교환잎 비료 구매도 보존한다. 배포는 Windows CI의 전체 게임·업데이터 검사와 EXE·Python-BAT 패키지 실행 검사를 거친다.


## 테스트 정원과 도감

개발자 모드의 무한 햇빛 토글이 켜지면 뽑기·일반 햇빛 구매를 테스트 결제로 처리하며 햇빛과 무료권을 소비하지 않는다. 결과·교환잎·천장은 별도 테스트 정원에만 저장한다. 도감은 157종의 소유/사용/해금/발견을 구분하고 개화 발견은 판매 후에도 남는다. 배경·화분은 꾸미기이며 능력치 장비 효과는 후속 범위다.

## 장미 씨앗 추가와 저장 v20

[장미 8색과 확률 근거](rose-varieties.ko.md)를 따른다. v19 씨앗 목록에 신규 장미 7종의 수량 0만 추가하고 나머지 ID·성장·재화·가챠 이력·개별 화분 설정을 보존한다. 최초 이전 원문은 버전별 백업으로 보존하며 클라우드 복원도 동일한 경로를 사용한다.
