게임 한 문장

하루 1~3분, 바탕화면 한쪽의 꽃을 돌보고, 자란 꽃으로 나만의 작은 정원을 채우는 게임.

플레이어가 느낄 재미

작은 변화 관찰: 어제의 새싹이 오늘 봉오리가 되는 변화를 발견한다. 짧게 돌본 행동은 물방울, 잎의 움직임, 꽃잎 변화로 즉시 확인한다.

돌봄의 선택: 관리 주기와 성장 속도가 다른 식물 중 내 생활에 맞는 식물을 고른다. 자주 클릭할수록 무조건 유리한 구조는 피한다.

성장의 소유: 완성한 꽃을 보관·전시하거나, 판매해 화분을 늘리거나, 꽃꽂이로 재구성한다. 플레이의 결과가 바탕화면에 남는다.

원안과 보완 제안

| --- | --- |
| 원안 유지 | PC / 직장인·대학생 / 힐링 육성 / 이동 가능한 정사각 플로팅 창 / 5개 화면 / 현실 시간 돌봄 / 1인 개발 |
| 구체화 제안 | 식물 5종, 성장·돌봄 수치, 경제, 꽃꽂이 거래 규칙, 저장 및 복귀 처리 |
| 변경 제안 | 아침 햇빛은 추가 보너스, 손상은 회복 가능, 테라리움 보관 후 관리 면제, 2D 전용 그래픽 |
| 후속 결정 | 아침 접속 의무 유지 여부, 꽃꽂이 출시 포함 여부, 유료 판매 방식 |

읽은 범위: 제공된 노션 본문 전체. 본문에서 연결된 별도 하위 기획 페이지는 확인되지 않았다. 원안의 빈 항목을 채운 제안서이며, 확정 사양이나 완성된 게임 빌드는 아니다.

기획 원문: 꽃 키우기 프로젝트

01  플레이 흐름과 첫 경험

반복 구조

씨앗 구매 → 빈 화분에 심기 → 필요할 때 돌보기 → 개화 → 테라리움에 보관 → 전시·판매·꽃꽂이 선택 → 새 품종과 화분 확보.

보관하면 재배 화분은 즉시 비워진다. 성장 완료 후 수확하지 않은 꽃은 그 상태로 유지되며, 추가 관리나 반복 수익을 요구하지 않는다.

첫 실행: 5분 안에 전체 순환 체험

| 시점 | 플레이어 행동 | 게임 반응 |
| --- | --- | --- |
| 0~1분 | 위치·크기 설정, 시작 씨앗 심기 | 화분 1개, 데이지 씨앗 1개, 120G 지급 |
| 1~2분 | 물주기와 오늘 할 일 확인 | 물방울 효과, 새싹 변화, 다음 관리 시각 표시 |
| 2~3분 | 블라인드·보관 기능 안내 | 튜토리얼 전용 꽃을 60초 안에 개화 |
| 3~5분 | 첫 꽃 보관 또는 판매, 재파종 | 데이지 씨앗 1개 추가 지급, 정상 시간으로 전환 |

첫 꽃 가속은 세이브당 1회다. 첫 꽃도 일반 판매가를 사용한다. 튜토리얼 초기화로 재화를 반복 지급하지 않는다.

생활 속 플레이 예시

평일 08:10: 화분을 열어 물·분무가 필요한 꽃만 돌본다. 블라인드를 올려 오늘의 햇빛 보너스를 확보하고 창을 관상 모드로 바꾼다. 예상 소요 1~3분.

저녁 20:00: 새 성장 단계를 확인한다. 개화한 꽃이 있으면 보관하고 빈 화분에 다음 씨앗을 심는다. 장식이나 꽃꽂이는 원할 때 5~10분 즐긴다.

주말 이후: 재접속 화면에 진행한 성장량과 필요한 돌봄을 묶어서 보여준다. 꽃이 시들었다면 무료 회복으로 다시 시작한다.

초기 목표

단기: 첫 개화와 첫 전시. 중기: 재배 화분 3개, 식물 5종 최초 개화 기록. 장기: 마음에 드는 꽃꽂이와 장식 배치 완성. 연속 출석 단절, 순위 경쟁, 기간 한정 손실은 초기 범위에서 제외한다.

02  화면 구성과 데스크톱 동작

원안의 화면 수는 상점·화분·가방·장식장·꽃꽂이의 5개로 해석한다. 기본 진입은 화분이며, 좌우 화살표와 현재 화면 이름으로 이동한다.

| 화면 | 기본 표시 | 핵심 조작 |
| --- | --- | --- |
| 상점 | 씨앗·추가 화분·바구니·장식 / 보유 G | 구매, 판매 탭, 수량·최종 금액 확인 |
| 화분 | 선택 식물 / 성장 단계 / 오늘 할 일 | 심기, 물, 분무, 비료, 온도, 블라인드, 보관 |
| 가방 | 씨앗·테라리움·용기·완성 꽃꽂이 | 정보, 심기, 전시, 제작 재료 선택, 판매 |
| 장식장 | 보관 식물과 작품의 전시 공간 | 배치, 이동, 회수, 즐겨찾기 |
| 꽃꽂이 | 용기, 재료 3개, 배치 미리보기 | 재료 선택, 위치·방향 조절, 완성, 취소 |

작은 창과 상세 화면

첫 실행 한 변은 현재 모니터 작업영역 너비의 20%를 기준으로 하되 320~520 논리 px로 제한한다. 1920px 너비·배율 100% 환경에서는 약 384px다. 작업표시줄을 피한 우하단에 배치하고 드래그 위치를 저장한다.

작은 창에는 꽃 1개, 상태 요약, 필요한 행동만 노출한다. 상점·가방·꽃꽂이는 확장 패널로 열어 설명과 금액을 읽을 수 있게 한다. 기본 글자는 14 논리 px 이상, 주요 버튼은 32px 이상을 목표로 한다.

투명도와 입력

원안의 “투명도 10~100”은 조작 혼동을 줄이기 위해 “불투명도 10~100%”로 표시한다. 100%는 선명, 10%는 거의 투명이다. 설정 패널은 선명도를 유지하고 “기본 상태로 복구”를 제공한다.

항상 위에 표시·관상 모드·소리 끄기를 각각 선택할 수 있다. 관상 모드는 창 조작을 잠그고 트레이 메뉴에서 복귀한다. 바탕화면으로 클릭을 통과시키는 기능은 별도 기술 검증 후 적용한다.

다중 모니터 연결 해제 시 주 모니터 안으로 위치를 복구한다. 자동 팝업이나 알림으로 다른 앱의 입력 포커스를 가져오지 않는다. 창 닫기 시 저장 후 종료하며 오프라인 성장을 지원한다.

03  식물 5종과 성장 규칙

아래 수치는 게임 밸런스 제안이다. 실제 식물의 원예·재배 기준을 의미하지 않는다. 성장 시간은 건강 상태가 유지되고 보너스가 없을 때의 기준이다.

| 식물 | 성장 | 물 간격 | 분무 / 주기 | 온도 | 씨앗 / 판매 |
| --- | --- | --- | --- | --- | --- |
| 데이지 | 24시간 | 48시간 | 1회 / 48시간 | 18~26℃ | 20 / 50G |
| 튤립 | 48시간 | 48시간 | 1회 / 48시간 | 16~22℃ | 35 / 100G |
| 라벤더 | 72시간 | 72시간 | 1회 / 72시간 | 18~28℃ | 45 / 130G |
| 해바라기 | 96시간 | 48시간 | 2회 / 48시간 | 20~28℃ | 60 / 180G |
| 장미 | 120시간 | 48시간 | 2회 / 48시간 | 18~26℃ | 80 / 240G |

단계와 상태 피드백

유효 성장 시간의 0~10%는 씨앗, 10~35%는 새싹, 35~70%는 성장, 70~100%는 봉오리, 100%는 개화다. 5종 × 5단계로 기본 식물 이미지 25장이 필요하다.

물·분무 타이머는 파종 시 가득 찬 상태에서 시작한다. 요구 간격의 마지막 12시간부터 “돌보기 가능”으로 표시한다. 물 1회 또는 정해진 분무 횟수를 완료하면 해당 타이머를 초기화한다. 분무 일부 진행도는 저장한다.

필요 시점 이전의 반복 클릭은 자원을 소모하거나 성장을 가속하지 않는다. 물과 분무는 무료다. 모든 화분을 한 화면에서 확인할 수 있고, 화분이 늘어나면 “필요한 돌봄만 실행”을 제공한다.

비료·온도·햇빛

비료: 모든 종에 7일마다 최대 1회, 사용 시 24시간 동안 성장 속도 +10%. 필수 관리가 아닌 선택 보너스로 제안한다. 상점 가격은 5G다.

온도: 실내 온도 조절기 1개로 전체 화분을 관리한다. 기본값 22℃로 5종의 범위를 모두 충족한다. 첫 출시에는 무작위 온도 급변을 넣지 않는다.

햇빛: 하루의 지정 시간대에 블라인드를 올리면 그날 보너스를 확보한다. 식물별 광량 퍼즐은 후속 확장으로 남긴다. 식물 구분은 우선 성장 시간·관리 간격·외형에서 만든다.

성장 계산

구간별 성장 증가량 = 경과 시간 × 건강 계수 × (1 + 햇빛 0.10 + 비료 0.10). 두 보너스는 합산해 최대 1.20배다. 성장 단계가 바뀌어도 같은 식물 개체 ID를 유지한다.

04  현실 시간과 실패·복귀 규칙

아침 루틴을 장점으로 만들기

원안은 07:00~11:00 블라인드 열기, 18:30 자동 닫기다. 초안은 이를 기본 생활 시간으로 유지하되, 기간 안에 한 번 열면 18:30까지 성장 +10%를 적용한다. 앱이 꺼져 있어도 해당 구간을 계산한다.

지정 시간에 접속하지 못하면 기본 속도로 성장한다. 햇빛 누락 자체로 시들지 않는다. 설정에서 4시간 길이의 돌봄 시간대를 바꿀 수 있고, 변경은 다음 날 적용한다. 자동 닫기는 선택 시간대 종료 7시간 30분 뒤로 함께 이동한다.

관리 누락과 회복

| 상태 | 진입 조건 | 결과 및 회복 |
| --- | --- | --- |
| 건강 | 필수 조건 충족 | 성장 계수 1.0 |
| 주의 | 물·분무 기한 초과 또는 온도 이탈 | 첫 24시간은 계수 1.0, 상태 안내만 표시 |
| 시듦 | 필수 조건 미충족이 연속 24시간 | 계수 0.0, 성장 일시 정지, 누적 성장 보존 |
| 회복 | 누락 돌봄 완료·온도 범위 복원 | 무료로 건강 복귀, 영구 품질 하락 없음 |

필수 조건 중 하나라도 미충족이면 공통 주의 타이머를 유지하고, 모두 충족했을 때만 해제한다. 비료와 햇빛 보너스는 손상 판정에서 제외한다. 판매가는 시듦 이력으로 깎지 않는다.

오프라인 처리

종료 시각과 식물 상태를 저장한다. 재접속 시 최대 72시간을 관리 만료·보너스 종료·개화 시점으로 나누어 계산한다. 건강 상태의 마지막 값만 전체 시간에 곱하지 않는다. 72시간을 넘는 부재는 보호 휴면으로 처리하고 추가 손상을 누적하지 않는다.

휴가 모드를 미리 켜면 성장과 돌봄 시계를 함께 멈춘다. 일반 종료와 달리 성장 보상은 없다. 시스템 시간이 뒤로 이동하면 추가 성장을 0으로 처리하고 저장 기준시각을 되돌리지 않는다. 오프라인 싱글 게임의 시간 조작을 완전히 차단하지는 않는다.

알림 정책

실행 중 돌봄 안내는 하루 최대 1회로 묶고, 개화 안내는 선택적으로 제공한다. 기본은 게임 내부 상태 표시, 소리는 끔이다. 완전 종료 상태의 OS 예약 알림은 첫 출시 필수 기능에서 제외한다.

05  상점과 화폐 순환

화폐는 G 하나만 사용한다. 수입은 성장 완료 식물·꽃꽂이 판매에서, 지출은 씨앗·추가 화분·용기·장식·선택 비료에서 발생한다. 현금 재화, 가챠, 실시간 시세는 초기 범위에 넣지 않는다.

| 항목 | 제안 가격 / 조건 |
| --- | --- |
| 시작 지급 | 120G + 재배 화분 1개 + 데이지 씨앗 1개 |
| 추가 재배 화분 | 2번째 150G / 3번째 300G / 4번째 600G / 최대 4개 |
| 테라리움 보관 | 무료, 재배 화분을 소모하지 않음 |
| 기본 꽃꽂이 바구니 | 30G / 식물 3개 수용 |
| 선택 비료 | 5G / 24시간 +10% / 식물당 7일 간격 |
| 장식 상품 | 50·100·200G 단계 / 성장 효율 영향 없음 |

기본 수익 검산

데이지 1회: 씨앗 20G → 24시간 성장 → 50G 판매 = 30G 순증가. 튤립은 48시간당 65G, 라벤더는 72시간당 85G, 해바라기는 96시간당 120G, 장미는 120시간당 160G 순증가다. 비료·보너스 없이 화분 1개 기준이다.

하루 환산 순증가는 약 28~33G로 맞췄다. 긴 성장 시간이 단순히 수익에서 손해가 되지 않게 하면서, 짧은 성장 식물은 자주 개화하는 경험을 제공한다.

첫 확장 예시: 120G 시작 → 튜토리얼 꽃 판매 +50G → 추가 화분 구매 −150G = 20G. 추가 지급 씨앗과 20G로 산 씨앗을 각각 심으면 정상 성장 화분 2개로 시작할 수 있다. 첫 꽃을 전시하면 확장이 늦어지는 선택이 된다.

막힘과 중복 거래 방지

심을 씨앗·성장 중인 식물·판매 가능한 식물이나 작품이 모두 없고 잔액이 20G 미만이면 구제용 데이지 씨앗 1개를 지급한다. 일반 성장 후 50G에 팔아 재파종할 수 있다. 구제 개체는 동시에 1개만 보유하며 꽃꽂이에 쓸 수 없다.

판매는 개체 ID 단위로 처리하고, 판매 완료 시 가방·전시·재료 참조에서 동시에 제거한다. 즐겨찾기 식물과 전시 중인 식물은 빠른 판매에서 제외한다. 구매·판매는 하나의 저장 거래로 완료한다.

열매 판매는 원안에 있으나 초기 5종의 꽃 중심 순환과 분리해 후속 콘텐츠로 둔다. 출시 가격과 수익화 방식은 이용자 테스트 뒤 별도로 결정한다.

06  보관·전시·꽃꽂이

식물 개체의 소유 규칙

개화한 식물을 “보관”하면 테라리움 개체로 바뀌며 추가 관리가 필요 없다. 가방에서 장식장에 배치해도 동일 개체를 참조한다. 동시에 여러 위치에 복제하지 않는다. 최초 개화 기록은 판매 이후에도 도감에 남는다.

장식장은 첫 보관 때 무료 해금한다. 첫 버전은 선반 6칸 배치와 회수만 제공한다. 원안의 야외 정원과 자유 배치는 다음 단계에서 확장한다. 가방 목록은 페이지로 나누고, 초기에는 유료 보관 한도를 두지 않는다.

미완성 꽃꽂이 화면의 규칙

용기 선택: 상점에서 산 바구니 1개를 선택한다. 기본 바구니는 식물 3개를 받는다. 꽃꽂이 진입 시 재료를 소비하지 않고 임시 선택 상태로 둔다.

재료 선택: 보관된 식물 3개를 고른다. 전시 중인 식물을 선택하면 전시에서 회수됨을 알린다. 즐겨찾기 식물은 잠금을 풀어야 쓸 수 있다.

배치: 용기 내부 3개 기준 위치에 놓고 방향과 앞뒤 순서를 조정한다. 첫 버전에서는 임의 크기 조절·물리 시뮬레이션을 제외한다. 2D 레이어로 꽃꽂이 결과를 합성한다.

완성: 결과 이름과 판매 예상가를 확인한 뒤 확정한다. 용기와 식물 3개를 하나의 작품 개체로 전환한다. 완성 전 취소는 원상 복귀한다. 완성 후 재료 분해는 초기 버전에서 지원하지 않는다.

제작 가치와 판매 공식

작품 판매가 = 재료 식물의 기본 판매가 합계 + 용기 구매가 + 완성 보너스 20G. 구제 식물은 재료 선택에서 제외한다. 색·종류별 효율 보너스는 넣지 않아 취향에 따라 배치할 수 있게 한다.

데이지 3개 예시: 개별 판매 합 150G + 바구니 30G + 완성 보너스 20G = 작품 판매 200G. 같은 재료를 개별 판매했을 때보다 용기 비용을 차감한 실질 수익이 20G 높다.

작품은 전시하거나 판매할 수 있다. 식물과 완성 작품의 상점 재구매는 지원하지 않는다. 작품 판매 후 원재료를 다시 지급하지 않아 분해·재판매 반복으로 재화를 만들 수 없게 한다.

원안 일정의 충돌 정리

본문은 교배를 “v3 이후”, 로드맵은 “v2.0”으로 달리 적고 있다. 이 초안에서는 교배를 버전 미정의 장기 확장으로 정리한다. 꽃꽂이는 원안 로드맵에 맞춰 v1.5를 기본으로 두되, 재료 소유 구조는 먼저 설계한다.

07  제작 방향과 첫 검증 범위

개발 도구 제안

Python + PySide6로 전환하는 방향으로 개발한다. 작은 네이티브 창과 2D 이미지 UI, 식물 상태와 저장을 분리한다. 창 이동·최상단 표시·불투명도는 실제 Windows에서 먼저 검증한다. 현재 저장소의 Godot 시제품은 초기 구현 기록으로 보존하며, Python 버전은 아직 구현되지 않았다.

기술 근거: Qt for Python 공식 QWidget 문서

꽃·화분·정원은 2D 이미지와 레이어로 구성한다. 성장 단계별 이미지 교체, 잎 흔들림, 물방울과 개화 효과를 사용한다. 꽃꽂이는 평면 위치·방향·앞뒤 순서를 조정한다. 모델링·실시간 조명·입체 카메라 회전은 제작 범위에서 제외한다.

아트와 사운드 제작

원안의 AI 나노바나나 이미지 제작과 AI 사운드 방향을 유지한다. 동일 시점·광원·화분 크기 기준으로 식물 25장, 시듦 공통 효과, UI 아이콘을 제작한다. 성장 단계 간 형태가 이어지도록 검수하고 작은 창에서 식물 실루엣이 구별되는지 확인한다.

물·분무·개화·구매 등 짧은 효과음과 선택형 환경음을 사용한다. 배경음은 기본 끔, 모든 효과는 음량 조절 가능하게 한다. 제작 자산별 생성 도구·원본·이용 조건을 기록한다.
