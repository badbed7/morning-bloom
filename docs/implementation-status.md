# 구현 상태 · v0.1

기획 초안은 제품 전체 목표이며, 현재 코드는 첫 수직 시제품입니다.

| 시스템 | 현재 상태 | 다음 작업 |
| --- | --- | --- |
| 플로팅 창 | 이동·위치 저장·불투명도·최상단 설정 | Windows DPI·다중 모니터 실기 검증 |
| 식물 | 데이지 1종, 씨앗→개화 5단계 | 나머지 4종 데이터화 |
| 시간 | 현실 시간, 최초 60초, 이후 24시간 | 햇빛·비료 구간별 보너스 |
| 돌봄 | 물·분무, 기한 48시간, 24시간 유예 | 종별 조건·전체 돌봄 UI |
| 실패·복귀 | 시듦 후 성장 정지·무료 회복·휴가 | 복귀 요약 확장 |
| 보관·경제 | 작은 보관함, 20G 씨앗·50G 판매 | 상점·가방 화면 분리, 추가 화분 |
| 저장 | 실제/데모 분리, 백업 복구, 읽기 전용 보호 | 저장 마이그레이션 |
| 장식·꽃꽂이·교배 | 미구현 | v1.0/v1.5 이후 |

## 시제품에서의 의도적 제한

- 정상 데이지는 24시간에 개화하고 물·분무는 48시간 뒤 기한이므로 보통 시듦을 겪지 않습니다. 장기 식물의 시듦·복귀 로직은 자동 테스트의 긴 성장 조건으로 검증합니다.
- 튜토리얼은 심은 순간부터 60초입니다. 첫 화분의 물주기·분무는 연출을 제공하며 성장 시간을 추가 지급하지 않습니다.
- 직접 판매와 재파종은 첫 순환 검증을 위해 v0.5 범위 일부를 앞당겼습니다. 전시·꽃꽂이가 생기기 전까지는 보관 꽃을 1개씩 판매합니다.
- 정상 플레이는 성장 중인 식물을 폐기하는 기능이 없어 기본 경제가 막히지 않습니다. 원안의 구제 씨앗은 폐기·확장 시스템 도입 시 함께 구현합니다.
- 현재 불투명도는 투명 배경 위 콘텐츠 알파 조절입니다. 설정·보관함은 읽기 쉬운 불투명 패널을 유지합니다. 다른 앱으로의 클릭 통과는 지원하지 않습니다.
- 단일 앱 인스턴스만 사용하세요. 다중 인스턴스 동시 쓰기 잠금은 아직 미구현입니다.

## 다음 개발 순서

1. 실제 Windows에서 투명 창·최상단·포커스·배율을 확인한다.
2. 식물/가격/관리 데이터를 Resource로 분리하고 두 번째 품종을 추가한다.
3. 상점·가방과 추가 화분 2~4개를 연결한다.
4. 선반 6칸과 최초 개화 도감을 만든다.
5. 사용 부담을 7일간 확인한 후 햇빛·비료 및 꽃꽂이로 확장한다.
