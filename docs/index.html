Windows desktop game

Morning Bloom

하루 1~3분, 바탕화면 한쪽에서 꽃을 심고 돌보며 작은 정원을 꾸미는 힐링 육성 게임입니다.

게임 소개

씨앗을 심고 물과 분무로 꽃을 돌봅니다. 성장한 꽃을 정원에 전시하거나 판매하고, 모은 햇빛으로 정원 배경과 화분 스킨을 꾸밀 수 있습니다.

Google Drive 연결

선택 기능인 Google 계정 연결을 사용하면 게임 저장 데이터를 사용자의 Google Drive 비공개 앱 데이터 폴더에 백업하고 복원합니다. Morning Bloom은 사용자의 일반 Drive 파일을 읽거나 수정하지 않습니다.
