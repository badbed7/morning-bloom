# 다음 개발 제안

## v0.4에서 반영됨

이전 제안이던 꽃별 성장 시간과 가격 차별화를 구현했다. 별꽃 3시간, 데이지 24시간, 튤립 48시간으로 나누고 씨앗·판매 가격, 물주기, 분무 보너스를 품종별로 적용했다. 세부 수치는 [v0.4 상세 기획](game-design-v0.4.ko.md)을 따른다.

## 다음 우선순위 제안

1. **플레이 관찰과 경제 조정**: 품종별 실제 선택률, 하루 수확 횟수, 순이익을 기록해 별꽃 반복 수확이 다른 꽃을 압도하는지 확인한다.
2. **별꽃 이름·아트 확정**: 현재 이름과 QPainter 도형은 시제품이므로 최종 식물 콘셉트와 성장 단계 이미지를 정한다.
3. **알림과 트레이**: 개화, 튤립 물주기 권장, 감속 시작 알림을 선택 설정으로 제공한다.
4. **수집 전시**: 보관 꽃을 판매 외에도 장식장이나 꽃꽂이에 사용하는 목표를 추가한다.
5. **환경 보너스**: 햇빛·비료·온도는 실패 페널티보다 선택 보상부터 작은 범위로 시험한다.

다음 구현 전에는 최소 며칠간 v0.4를 직접 플레이해 3시간·24시간·48시간 주기가 실제 생활 리듬에 맞는지 먼저 확인한다.
