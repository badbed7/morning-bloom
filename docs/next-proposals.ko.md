# 다음 개발 제안

## v0.4에서 반영됨

이전 제안이던 꽃별 성장 시간과 가격 차별화를 구현했다. 별꽃 3시간, 데이지 24시간, 튤립 48시간으로 나누고 씨앗·판매 가격, 물주기, 분무 보너스를 품종별로 적용했다. 세부 수치는 [v0.4 상세 기획](game-design-v0.4.ko.md)을 따른다.

## 이번에 추가한 기획

최우선 후속 범위는 [햇빛 수집·정원 꾸미기](sunlight-interaction.ko.md)다. 정원에 보관한 꽃에서 주기적으로 햇빛이 생기고, 사용자가 클릭하면 터지는 효과와 함께 전용 재화를 얻는다. 상점에서 정원 배경을 구매·적용하며, 재배 능력치는 바꾸지 않는다. 시간·상한·가격은 문서에 초기 제안값으로 구분했다. 햇빛 기능 자체는 아직 미구현이다.

설정의 개발자 모드와 테스트 정원의 `+6시간`은 이번에 구현한다. 일반 재배 저장과 분리하며, 향후 햇빛 주기도 같은 개발용 시계로 검증한다. EXE 빌드·릴리스 게시·자동 업데이트 배포 작업은 사용자 요청에 따라 보류한다.

## 이후 우선순위 제안

1. **플레이 관찰과 경제 조정**: 품종별 선택률·수확 간격·순이익과 햇빛 수집 빈도를 관찰해 반복 클릭이 부담스럽지 않은지 확인한다.
2. **꾸미기 확장**: 배경 다음으로 화분 스킨·정원 소품·수집 효과를 검토한다. 장식장·꽃꽂이는 별도 범위다.
3. **별꽃 이름·아트 확정**: 현재 이름과 QPainter 도형은 시제품이므로 최종 식물 콘셉트와 성장 단계 이미지를 정한다.
4. **알림과 트레이**: 개화, 튤립 물주기 권장, 감속 시작 알림을 선택 설정으로 제공한다. 햇빛 수집을 재촉하는 알림은 기본으로 넣지 않는다.
5. **환경 보너스**: 비료·온도는 별도 검토한다. 새 햇빛 재화는 꾸미기 전용으로 유지한다.

기존 3시간·24시간·48시간의 꽃별 특성은 유지하면서 며칠간 생활 리듬에 맞는지 확인한다.
