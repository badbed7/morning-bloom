Morning Bloom

개인정보처리방침

시행일: 2026년 9월 17일

수집하고 사용하는 정보

Google 계정 연결은 선택 사항입니다. 연결하면 Morning Bloom은 계정 식별과 연결 상태 표시를 위해 Google 계정 이메일 주소와 기본 프로필 인증 정보를 요청하고, 게임 저장 데이터의 백업과 복원을 위해 drive.appdata 권한을 요청합니다.

정보의 이용 목적

Google 사용자 데이터는 연결된 계정 확인, 사용자가 요청한 게임 저장 백업, 기기 간 저장 복원에만 사용합니다. 일반 Google Drive 파일에는 접근하지 않습니다.

저장과 전송

게임 저장은 사용자 PC와 사용자의 Google Drive 비공개 앱 데이터 폴더에 저장됩니다. 장기 로그인 토큰은 사용자 PC의 Windows 자격 증명 관리자에 저장됩니다. 액세스 토큰은 실행 중에만 메모리에서 사용합니다. 다른 PC에서 변경된 저장을 감지하기 위해 이메일 주소의 단방향 해시와 마지막 성공 백업 지문을 로컬 동기화 상태 파일에 보관하며, 이 파일에는 토큰이 포함되지 않습니다. 개발자가 운영하는 별도 서버로 Google 사용자 데이터나 게임 저장을 전송하지 않습니다.

공유 및 판매

Google 사용자 데이터를 광고, 분석 또는 판매에 사용하지 않으며 제3자에게 공유하지 않습니다. 인증과 클라우드 저장 기능 제공 과정에서 Google 서비스가 데이터를 처리합니다.

보관과 삭제

설정에서 Google 계정 연결을 해제하면 권한을 철회하고 PC에 저장된 로그인 정보를 삭제합니다. Google Drive 비공개 앱 데이터에 남은 게임 저장은 사용자가 Google Drive의 앱 관리에서 삭제할 수 있습니다. 로컬 게임 저장은 사용자가 앱 데이터 폴더를 삭제할 때까지 유지됩니다.

보안

Morning Bloom은 데스크톱 OAuth Authorization Code 방식과 PKCE를 사용합니다. Google OAuth Client Secret을 앱에 포함하지 않습니다.
