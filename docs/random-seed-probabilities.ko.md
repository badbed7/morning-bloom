# 랜덤 씨앗 · 전체 식물 등급별 확률

2026-11-12 · v0.8.22. [릴리즈 변경 사항](../release/notes/v0.8.22.md).

## 구매당 확률

상점 랜덤 씨앗은 기존과 같은 **20G**다. 민들레를 제외한 **28종**을 포함한다. 등급 비율은 **R 80% / SR 19% / SSR 1%**로 정하고, 보드·천장 없이 구매마다 독립 추첨한다. 꽃길 가챠의 일반 칸(R 70% / SR 25% / SSR 5%)보다 고등급 비율을 낮춰 가챠와 차이를 둔다. 이는 게임 밸런스 값이며 실제 식물의 자연 발생 확률을 뜻하지 않는다.

| 등급 | 품종 수 | 등급 합계 | 개별 품종 확률 |
|---|---:|---:|---:|
| R | 12 | 80% | 각각 80% ÷ 12 = 6.6666…% |
| SR | 10 | 19% | 각각 1.9% |
| SSR · 고대 꽃 외 | 5 | 0.9% | 각각 0.18% |
| SSR · 고대 꽃 | 1 | 0.1% | 0.1% |
| 합계 | 28 | 100% | |

고대 꽃의 0.1%는 SSR 1%에 포함된다. 추첨은 정확한 분수를 정수 티켓으로 변환해 총 15,000장 중 하나를 한 번 고른다. R 품종은 각 1,000장, SR은 각 285장, SSR 일반 품종은 각 27장, 고대 꽃은 15장이다. 표시 반올림은 추첨에 사용하지 않는다.

## 전체 품종

기존 장미 8색과 관엽식물 8종의 가챠 등급을 공유한다. 상점 일반 식물은 성장 기간을 참고해 빠른 재배 R / 중장기 재배 SR / 은방울꽃 SSR로 배치했다.

| 등급 | 식물 |
|---|---|
| R | 별꽃, 데이지, 튤립, 빨강 장미, 토끼풀, 물망초, 스투키 바리에가타, 리톱스, 부르고뉴 고사리, 핑크 장미, 하양 장미, 노랑 장미 |
| SR | 팬지, 코스모스, 프리지아, 해바라기, 라벤더, 호야 크림슨 퀸, 칼라디움 화이트 핑크, 알로카시아 블랙 벨벳, 주황 장미, 보라 장미 |
| SSR · 각각 0.18% | 은방울꽃, 몬스테라 알보, 필로덴드론 핑크 프린세스, 파랑 장미, 검정 장미 |
| SSR · 0.1% | 고대 꽃 |

랜덤 씨앗에서는 고대 꽃 외에 같은 등급의 품종을 균등하게 배분한다. 기존 장미 전용 가챠의 등급 내 색상 가중치와 꽃길 보드·천장 확률은 그대로다.

## 재배·발견·상점 해금

- 민들레는 홀씨 바람놀이 완료 보상으로 유지하고 랜덤 씨앗에서는 제외한다.
- 구매한 랜덤 씨앗은 정체가 숨겨진 봉투로 보유한다. 구매·재실행·심기·재배 도중 저장·복원해도 정해진 품종이 바뀌지 않는다. 이미 구매한 씨앗과 심어둔 작물도 다시 추첨하지 않는다.
- 해금 전 관엽식물과 장미도 랜덤 씨앗으로 재배할 수 있다. 품종별 성장 시간·판매가를 사용하고 개화 후 도감에 기록한다. 랜덤 씨앗 획득만으로 지정 씨앗 상점을 영구 해금하지 않는다.
- 관엽식물 지정 씨앗은 기존처럼 식물 가챠로 상점 해금 후 구매한다. 장미는 빨강만 지정 씨앗을 상점에서 구매하며 나머지 7색은 장미 가챠 또는 랜덤 씨앗으로 얻는다.
- 기존 저장 형식(v21), 소유권·지정 씨앗·재화·가챠 기록은 유지한다. 확률표 조회는 저장 상태를 변경하지 않는다.

## 화면·검증

상점에서 랜덤 씨앗을 선택하면 28종과 등급 확률을 안내하고 **랜덤 씨앗 확률 보기**에서 모든 품종의 구매당 확률과 정확한 분수를 표시한다. 씨앗 선택 도움말·설정·수집 도감의 획득 경로도 함께 갱신한다.

15,000개 전체 티켓의 실제 결과, 28종 포함·민들레 제외, 등급별 합계, 가챠 등급 일치, 추첨 경계, 잘못된 추첨값, 모든 품종의 구매→저장→재실행→재배→발견→판매 및 기존 결과 보존을 검사한다. Qt에서는 상점의 확률표 표시·조회 시 재화와 숨겨진 결과 보존을 확인한다.
