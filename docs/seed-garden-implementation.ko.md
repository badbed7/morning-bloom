# 씨앗 정원 여행 구현

2026-10-17, Python/PySide6 게임의 개발 브랜치에 구현했다. 현재 공개 Release의 버전 번호는 변경하지 않는다.

## 사용 방법

상점 맨 위의 `씨앗 정원 여행`을 연다. `주사위 여행`, `도감 · 장착 · 교환`, `확률 · 보상 이력`을 사용할 수 있다.

상점 첫 화면의 **가챠 · 씨앗 정원 여행** 카드에서 보유 주사위·꽃잎과 이번 주 주사위 수령 가능 여부를 확인한다. `꽃잎 교환`은 교환 목록으로 바로 이동한다. 미해금 아이템을 고르고 아래 꽃잎 해금 버튼을 누르면 C3/B8/A20/S40개로 해금한다.

뽑거나 교환한 정원·화분은 상점의 **정원 배경·화분 스킨** 선택 목록에 자동 추가된다. 획득 직후 새 항목을 선택해 보여 주며, 화살표로 다른 항목을 넘겨 볼 수 있다. 배경은 `정원에 적용`, 화분은 `선택 화분에 적용`을 눌러 장착한다. 효과·등급·전체 이름도 선택 항목 아래에서 확인한다.

- 월요일 00:00 한국 시각 기준, 해당 주 첫 보드 진입 때 주사위 5개를 지급한다. 이월하며 미접속 주를 소급하지 않는다.
- 실제 1~6 주사위로 20칸 보드를 시계 방향으로 이동한다. 지나친 입구는 발동하지 않는다.
- 좌우 입구(8번·18번)에 정확히 멈추면 추가 주사위 소비 없이 A/S 아이템 1개를 받는다. 무료 추첨 후 도착했던 입구에서 계속한다.
- 일반 칸의 등급은 C 5/9, B 3/9, A 1/9이다. 스페셜의 A/S × 씨앗/정원/화분 6가지 결과는 각각 1/6이며, 해당 등급·분류 안의 개별 아이템은 균등 추첨한다.
- 장기 평균 등급 비율은 C 50%, B 30%, A 15%, S 5%이다. 시작 위치에서 매회 독립적으로 이 확률을 적용하는 구조는 아니다.
- 보상마다 꽃잎 1개, 중복이면 C1/B2/A5/S10개를 추가한다. 미해금 항목만 C3/B8/A20/S40개로 선택 교환한다. 교환은 꽃잎을 다시 지급하지 않는다.
- 새 씨앗 획득은 품종 해금과 씨앗 1개를 함께 준다. 해금 후 씨앗 상점에서 골드로 재구매한다.
- 고대 꽃은 기존 랜덤 씨앗 0.1%, 민들레는 홀씨놀이 경로를 유지한다. 기본 정원 4종과 화분 4종도 기존 지급·햇빛 구매 경로를 유지한다.

## 콘텐츠와 효과

식물 22종, 정원 83종, 화분 45종을 S/A/B/C로 분류한다. 보드 풀은 씨앗 20종·신규 정원 79종·신규 화분 41종, 총 140종이다. 도감은 제외 항목까지 150종을 표시한다.

신규 식물 8종의 5단계 벡터 외형과 실제 재배를 연결했다. 신규 정원과 화분도 코드로 그리는 외형을 사용한다. 원본 레퍼런스 그림은 도감 미리보기로 보존한다.

정원·화분 128종 모두 별도 효과를 가진다. 재배 화분 번호를 선택해 화분 스킨을 개별 장착하고, 정원은 전체 외관에 적용한다. **첫 물주기 때 장착 효과를 기록**한다. 이후 외관 변경은 즉시 보이며, 변경한 효과는 다음 재배에 적용한다. 수확한 꽃의 화분 외형도 개체별로 보존한다.

성장 속도 합산 +20%, 장비 판매 보너스 합산 +25%, 물·분무 대기 감소 합산 20%, 햇빛 주기 감소 15%, 장비 직접 성장 단축은 기본 시간의 10% 상한이다. 비료의 실제 총 단축은 기본 시간의 25%(시멘트 26%) 이내다. 판매 소수점은 저장해 골드가 사라지지 않게 누적한다.

첫 분무는 기존처럼 즉시 할 수 있다. 이끼 느낌과 핑크빛 잔디의 첫 분무 대기 효과는 **첫 분무 완료 후 다음 분무 대기**를 줄이도록 상세 기획과 문구를 맞췄다. 핸들 스톤의 첫 비료는 재고가 1개 이상일 때 사용하며 재고를 소모하지 않는다.

개별 수치·조건·신규 식물 가격은 [상세 기획](seed-garden-development-plan.ko.md)과 `python/morning_bloom/content_data.json`에 있다.

## 저장과 복구

저장 v14는 보드 위치, 주간 지급 ID, 주사위·꽃잎, 해금 목록, 슬롯 장착, 재배 효과, 햇빛 주기와 최근 보상 200건을 기록한다. v1~v13 검증은 변경하지 않은 역사적 정의를 사용해 순차 이전한다. 기존에 심은 꽃은 수확까지 원래 성장·돌봄·가격을 유지한다.

추첨은 결과를 고정해 저장한 다음 재화 차감·보상을 지급하고 다시 저장한다. 첫 저장 실패는 상태를 되돌린다. 두 번째 저장 실패는 고정된 거래를 유지하며, 재시도와 재시작에서 같은 거래를 한 번 완료한다. 미완료 스페셜도 저장되며 무료로 이어서 받을 수 있다. 클라우드 복원에도 같은 검증을 적용하고 로컬 원본을 별도 보관한다.

## 검증

```powershell
$env:PYTHONPATH='python'
$env:QT_QPA_PLATFORM='offscreen'
python -m unittest discover -s python/tests -v
$env:PYTHONPATH='release'
python -m unittest discover -s release/tests -v
python release/game_entry.py --smoke-test
python release/build_windows.py
python release/build_python.py
```

추가 검사는 120가지 이동 조합, 두 입구의 6가지 무료 결과, 정확한 등급 티켓 비율, 한국 시각 주간 경계, 중복·교환, 두 저장 단계 실패와 재시작, 기존 저장 보존, 128개 장비의 재배·수확·판매, 성장 구간 분할 불변성, 상한, 슬롯 장착과 150개 도감 아이콘을 다룬다.

로컬 개발 검증 환경은 Windows/Python 3.11/PySide6 6.8.3이다. 저장소 Windows CI는 Python 3.12로 실행한다. 실제 장기간 플레이의 경제 균형과 여러 DPI·모니터 환경은 후속 사용 검증 대상이다.
