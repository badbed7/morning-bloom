# 타이쿤 돌봄·비료 미니게임 변경안

작성일·보완일: 2026-09-16. 기획 초안 v0.2. 기준 코드: `main`의 `91ab1b8`.
상태: **첫 범위를 Python에 구현했다.** 최대 네 화분, 반복 돌봄, 비료, 타이밍 미니게임을 적용했다. 타이쿤 저장은 v6으로 도입했으며 화분 스킨 추가 후 현재 저장은 v7이다. 최대 여섯 화분과 일괄 돌봄은 후속 기획이며 경제·사용성 목표는 플레이 관찰 전 제안값이다.

2026-09-16 UI 재작업: 개별 화분 선택은 양 끝에서 멈추는 좌우 슬라이드를 사용한다. [선택 UI](garden-ui-revision.ko.md)에 네 화분과 전체 준비 요약을 연결했다. 빈 화분과 재배 상점에서는 씨앗 봉투 아이콘을 사용하고, 성장 중에는 물·분무·비료, 개화 후에는 정원 보관 버튼을 표시한다. 원형 화살표는 얇은 꺾쇠로 바꾸고 코티지 색감을 적용했다. 비료 재고·만들기는 공용 도구 영역으로 분리한다. 미니게임에도 본체의 불투명도를 적용하고, 제목·닫기·라운드별 결과·단계별 조작 버튼으로 화면을 정리했다.

## 1. 요청 사항과 제안값

동시에 키우는 화분 수를 늘리고 돌봄 횟수와 간격을 바꿔 짧게 자주 개입하는 타이쿤 요소를 늘린다. 단순한 미니게임으로 비료를 얻고, 비료 한 개를 사용하면 선택한 화분의 남은 성장 시간을 10분 줄인다.

사용자가 지정한 **동시 재배 화분 수 확대**와 **비료 1개 = 성장 시간 10분 단축**은 고정 요구사항이다. 아래 목표 화분 수, 반복 간격, 추가 돌봄 효과, 미니게임 방식·보상 제한은 구현을 위한 제안값이다.

| 항목 | 적용 전 기준 | 첫 적용 및 후속 제안 |
| --- | --- | --- |
| 동시 재배 화분 | 최대 2개 | 1차 최대 4개, 이후 최대 6개로 확장 |
| 물주기 | 별꽃·데이지는 첫 물 1회, 튤립은 첫 물과 중간 물 | 첫 물 뒤 30분 간격으로 반복 가능 |
| 분무 | 첫 물 뒤 개화 전까지 꽃당 1회 | 첫 물 뒤 즉시 1회, 이후 15분 간격으로 반복 가능 |
| 반복 물의 효과 | 튤립 중간 급수로 감속 예방·회복 | 첫 물은 성장 시작, 추가 물은 남은 성장 3분 단축 |
| 반복 분무의 효과 | 한 번만 기본 판매가의 10% 보너스 | 매회 남은 성장 1분 단축, 첫 분무만 기존 판매 보너스 지급 |
| 미니게임 | 없음 | 3번 타이밍 맞추기, 한 판 최대 12초 |
| 미니게임 보상 | 없음 | 보상 가능한 판에서 성공하면 비료 1개 |
| 비료 효과 | 없음 | 선택한 화분의 남은 성장 10분 단축 |

사용자 확인: ‘화분 개수’는 **동시에 키우는 화분을 늘린다**는 뜻이다. 목표 수치는 미지정이므로 2→4→6개 단계 확장을 제안한다. 한 번의 개별 물주기·분무 대상은 선택한 화분 한 개다.

정원에 전시하는 수집 꽃의 수는 재배 화분 수와 별개다. 새 재배 화분을 사면 동시에 키울 수 있는 꽃이 늘어나며, 수확한 꽃은 기존 정원에 계속 보관할 수 있다.

## 2. 목표 플레이 흐름

`여러 화분에 심기 → 화분별 첫 물 → 준비된 화분 돌보기 → 미니게임 → 우선할 화분에 비료 사용 → 개화·수확 → 판매 수익으로 화분 확장`

반복 돌봄을 하면 더 빨리 수확한다. 첫 물을 준 뒤에는 추가 조작 없이도 기본 속도로 자라게 하여, 일하는 중에 돌봄 시각을 놓쳤다고 꽃이 죽거나 품질이 떨어지지 않게 한다. 새로운 반복 돌봄 규칙에서는 튤립의 기존 22·24·30시간 중간 급수와 50% 감속을 대체한다. 기존 규칙으로 심은 꽃은 전환 규칙에 따라 끝까지 기존 계산을 사용한다.

품종별 기본 성장 3·24·48시간, 씨앗 가격, 기본 판매가, 햇빛 20분 주기·대기 상한 9개는 첫 적용에서 유지한다. 반복 돌봄·비료 때문에 실제 수확 주기는 짧아지므로 이후 수익을 관찰해 조정한다.

### 화분 확장과 투자

화분은 골드로 한 칸씩 구매한다. 첫 개발 단계에서는 최대 4개를 구현하고, 화면·경제를 확인한 뒤 최대 6개를 연다. 기존 한두 화분 보유 상태에서 이어 가며 새 저장의 시작 화분은 한 개다.

| 재배 화분 | 구매 비용 제안 | 구분 |
| --- | ---: | --- |
| 1번 | 무료 | 기존 기본 화분 |
| 2번 | 150G | 기존 가격·소유권 유지 |
| 3번 | 200G | 1차 확장 |
| 4번 | 300G | 1차 확장 |
| 5번 | 450G | 후속 확장 |
| 6번 | 650G | 후속 확장 |

3번 이후 가격과 단계 경계는 제안값이다. 구매는 앞 화분부터 순서대로 열고, 잔액 부족·중복 구매·상한 초과를 차단한다. 슬롯과 골드를 함께 저장하고 실패하면 함께 복원한다.

각 화분은 선택 여부와 관계없이 독립적으로 성장하고 물·분무 대기시간도 각각 가진다. 미니게임 비료는 공용 재고이므로 빠른 판매용 꽃과 오래 키우는 꽃 중 어디에 쓸지 선택한다. 화분 수가 늘어도 미니게임 보상이 화분별로 중복 지급되지는 않는다.

## 3. 물주기·분무 상세 규칙

### 공통 규칙

- 한 번의 행동은 선택한 재배 화분 한 개에만 적용한다. 정원의 전시 꽃에는 물·분무·비료를 사용하지 않는다.
- ‘30분·15분’은 다음 행동까지의 **재사용 대기시간**이다. 잠깐만 누를 수 있는 제한 시간이나 알림에 즉시 반응해야 하는 창이 아니다.
- 대기시간이 끝나면 다음 성공 행동까지 계속 사용할 수 있다. 늦게 눌러도 기회를 잃지 않는다.
- 사용 기회는 행동별 최대 한 번만 준비된다. 한 시간 비웠다고 물 두 번·분무 네 번을 연속으로 몰아서 쓰지 않는다.
- 성공한 행동 시점부터 해당 행동의 다음 대기시간을 센다. 물주기와 분무 시계는 서로 독립적이다.
- 행동 직전까지 실제 경과 시간을 먼저 계산한다. 물·분무의 성장 단축이 남은 시간을 넘으면 그만큼만 반영해 개화하며, 다른 행동의 대기시간이나 햇빛 시계는 앞당기지 않는다.
- 꽃이 이미 피었거나 화분이 비어 있으면 사용할 수 없다. 모든 버튼은 남은 시간·완료 상태를 표시한다.
- 첫 데이지 60초 안내에서는 첫 물주기만 진행한다. 반복 돌봄·비료와 미니게임은 첫 수확 이후 해금한다.

### 물주기

1. 심은 직후 `첫 물주기`로 성장을 시작한다. 첫 물 자체는 별도의 성장 단축을 주지 않는다.
2. 첫 물로부터 30분 뒤 `물주기 · 성장 -3분`이 활성화된다.
3. 추가 물을 성공하면 성장량을 정상 속도 기준 180초 더하고 물주기 대기시간만 30분으로 되돌린다.
4. 반복 횟수에 꽃당 한 번 제한을 두지 않는다. 재사용 대기시간과 개화 여부가 횟수를 제한한다.

### 분무

1. 첫 물을 준 뒤 첫 분무를 바로 사용할 수 있다. 이후에는 성공한 분무로부터 15분을 기다린다.
2. 매 분무마다 성장량을 정상 속도 기준 60초 더한다.
3. 첫 분무에서만 기존 판매 보너스 `floor(기본 판매가 × 10%)`를 확정한다. 별꽃 +1G, 데이지 +5G, 튤립 +10G다.
4. 두 번째 이후 분무는 성장 단축만 준다. 판매 보너스를 반복해서 쌓지 않는다.

예: 첫 물이 09:00이면 물은 09:30부터 준비된다. 첫 분무가 09:05이면 다음 분무는 09:20부터 준비된다. 10:00에 돌아와도 물 한 번과 분무 한 번만 준비되어 있으며, 실제로 누른 시각부터 각각 다시 30분·15분을 센다.

## 4. 미니게임 — 비료 섞기

복잡한 규칙 없이 움직이는 표시를 초록 구간에서 멈추는 타이밍 게임을 제안한다. 화분 화면의 `비료 만들기` 버튼으로 열며 상단 화분·상점·정원 순환 메뉴는 유지한다.

| 항목 | 제안 |
| --- | --- |
| 조작 | `멈추기` 버튼 클릭 또는 스페이스 키 |
| 한 판 구성 | 3라운드, 라운드마다 입력 1번 |
| 라운드 제한 | 최대 4초. 시간 초과는 해당 라운드 실패 |
| 목표 구간 | 막대 너비의 약 30%, 라운드마다 중앙 부근에서 위치 변경 |
| 성공 기준 | 3라운드 중 2번 이상 초록 구간 안에서 멈춤 |
| 총 플레이 시간 | 최대 12초, 결과 화면 제외 |
| 성공 보상 | 비료 1개 |
| 실패 처리 | 비용·벌점 없음, 즉시 재도전 가능 |

- `시작` 입력과 첫 라운드의 `멈추기` 입력을 분리한다. 키를 누르고 있는 자동 반복은 추가 입력으로 받지 않는다.
- 더블클릭이 다음 라운드를 즉시 처리하지 않도록 다음 라운드는 키·마우스를 놓은 뒤 입력을 받는다.
- 창 닫기·다른 화면 이동·다른 앱으로 전환은 해당 판을 취소한다. 취소는 실패와 동일하게 보상·비용이 없다. 기다려야 하는 보상 대기시간도 시작하지 않는다.
- 미니게임은 실제 플레이 중인 시간을 사용한다. OS 시각 변경이나 개발자 `+6시간`으로 성공 판정을 만들 수 없다.

### 보상 빈도와 재고

- 보상 가능한 성공 1회당 비료 1개를 지급하고, **성공 보상이 저장된 시점부터 30분**의 공통 보상 대기시간을 시작한다.
- 실패·취소는 보상 대기시간을 만들지 않는다. 성공했더라도 연습 판에는 보상이 없다.
- 대기 중에도 `연습 · 보상 없음`으로 플레이할 수 있다. 시작 화면에서 실전과 연습을 구분한다.
- 비료 보유 상한은 **10개**를 제안한다. 가득 차면 시작 전에 사용을 안내하고 연습만 제공한다. 받을 자리가 없는데 실전 성공을 소모하지 않는다.
- 비료를 써도 미니게임 보상 시각은 초기화하지 않는다. 상점을 열거나 재실행해도 시각이 유지된다.
- 대기시간은 저장 파일 전체에 하나다. 화분·품종 변경으로 중복 보상을 얻을 수 없다. 일반 정원과 개발자 정원은 현재처럼 각각 분리한다.
- 오프라인 시간은 보상 가능 상태만 준비한다. 앱을 끈 동안 미니게임 보상이나 비료가 자동으로 쌓이지 않는다.

## 5. 비료 사용 규칙

비료는 골드·햇빛과 분리한 **소모 아이템**이다. 초기 획득 경로는 미니게임만 제공한다. 햇빛은 꾸미기 전용으로 유지한다.

1. 성장 중인 새 규칙 화분에서 `비료 1개 사용 · 성장 -10분`을 누른다.
2. 실제로 경과한 재배 시간을 먼저 계산하고, 여전히 성장 중이면 비료 1개를 차감한다.
3. 그 화분의 성장량에 600초를 더한다. 전역 시각, 다른 화분, 돌봄 대기시간, 햇빛 생산, 미니게임 보상 대기시간은 이동하지 않는다.
4. 남은 시간이 10분 미만이면 남은 시간만 줄여 개화한다. 사용 전 버튼 도움말에 `즉시 개화 · 비료 1개 사용`을 표시하고 잔여 효과를 별도 아이템으로 반환하지 않는다.
5. `+6시간`과 달리 실제로 선택한 작물 하나에만 영향을 준다.

| 상태 | 처리 |
| --- | --- |
| 빈 화분·이미 개화 | 사용 불가, 비료 유지 |
| 첫 물 이전 | `첫 물주기 후 사용 가능` |
| 첫 60초 튜토리얼 | 사용 불가 |
| 휴가 중 | 사용 불가 |
| 비료 없음 | `비료 만들기` 안내 |
| 기존 규칙으로 재배 중 | 이번 꽃은 기존 규칙 유지, 다음 새 재배부터 사용 가능 |
| 작물별 사용 상한 도달 | 상한 표시, 비료 유지 |
| 저장 실패 | 비료 수량·성장량·사용 횟수 함께 복원 |

비료만 모아 즉시 재배를 무한 반복하지 않도록 **작물당 기본 성장 시간의 25% 이내**까지 비료로 단축하는 것을 제안한다. 사용 가능 개수는 `floor(기본 성장 초 × 0.25 / 600)`으로 고정한다.

| 품종 | 기본 성장 | 비료 사용 상한 | 비료의 최대 단축 |
| --- | ---: | ---: | ---: |
| 별꽃 | 3시간 | 4개 | 40분 |
| 데이지 | 24시간 | 36개 | 6시간 |
| 튤립 | 48시간 | 72개 | 12시간 |

이 상한은 비료만 대상으로 한다. 반복 물주기·분무의 작은 성장 보상은 별도다. 기본 성장 시간과 상한은 심는 시점의 규칙으로 작물에 저장한다. 가격이나 규칙을 바꿔도 이미 심은 꽃의 사용 상한을 다시 계산하지 않는다.

예: 남은 성장 시간이 25분인 화분에 비료 1개를 쓰면 15분이 된다. 물주기 대기 12분, 분무 대기 4분, 다음 햇빛 8분, 미니게임 보상 대기 20분은 그대로다. 남은 성장 시간이 7분일 때 사용하면 바로 개화하고 비료는 1개 소모한다.

## 6. 화면과 피드백

- 화분: `‹ 화분 1 / 보유 개수 · 꽃 이름 ›` 좌우 슬라이드를 사용한다. 왼쪽은 이전, 오른쪽은 다음 화분이며 첫 화분의 이전·마지막 화분의 다음 버튼은 비활성화한다. 양 끝은 이어지지 않는다. 선택 화분의 그림·성장률·물/분무 준비·개화 여부와 상세 돌봄 도구를 보여준다. 화분을 넘겨도 각 화분의 성장과 대기시간은 유지한다.
- 돌봄 버튼: 물주기·분무의 준비 상태 또는 `12:30` 형태의 남은 대기시간을 표시한다. 첫 물 전에는 성장 시작 안내를 우선한다. 반복 돌봄의 초기 입력은 화분별로 하며, 일괄 돌봄은 화분 수가 늘었을 때의 후속 편의 기능으로 검토한다.
- 화분 준비 요약: 슬라이드 아래에 `첫 물 1 · 물 2 · 분무 3 · 개화 1`처럼 보유 화분 전체의 준비 상태를 보여준다. 화분을 일일이 넘기기 전에 할 일을 파악하게 하며, 요약은 선택 UI나 일괄 실행 버튼으로 사용하지 않는다. 첫 물 대기와 반복 물 준비를 따로 세고 빈 화분·개화한 화분·기존 규칙 작물은 해당 상태에 맞게 집계한다.
- 비료: 보유량 `비료 3/10`, 만들기 버튼, 선택 화분의 사용 가능 횟수와 사용 후 남은 시간을 표시한다.
- 사용 효과: 작은 물방울·분무 입자·비료 반짝임과 함께 `성장 -3분 / -1분 / -10분`을 보여준다. 저장 성공 후에만 성공 효과를 재생한다.
- 미니게임: 시작 전에 보상 유무를 표시하고, 완료 후 `성공 → 비료 +1` 또는 `다시 해보기`를 제공한다. 자동 재시작하지 않는다.
- 알림: 기본적으로 앱 안의 준비 표시만 제공한다. 짧은 간격의 돌봄을 재촉하는 OS 알림은 기본으로 넣지 않는다.
- 좁은 창: 320·384·520px에서 기존 화분·상점·정원 이동과 설정 버튼을 가리지 않는다. 필요하면 돌봄 도구를 접었다 펼치는 영역으로 배치한다.

## 7. 화분 확장·기존 저장 전환

- 기존 저장의 한두 화분과 구매 이력을 유지한다. 새 저장은 기본 화분 한 개로 시작하고 상점에서 최대 네 개까지 순서대로 늘린다. 여섯 개 개방은 후속 단계다.
- 이미 재배 중인 꽃은 기존 성장·돌봄·판매가 규칙으로 수확까지 유지한다. 기존 두 번째 화분도 수확 이후 계속 사용할 수 있다.
- 비어 있는 기존 화분과 새로 구매한 화분에서 심는 다음 작물부터 새 반복 돌봄 규칙을 사용한다. 다른 화분의 기존 작물을 기다리지 않고 추가 화분을 구매·재배할 수 있다.
- 저장 전후 화분 ID·선택 상태·작물 가격을 보존한다. 정원의 수집 꽃·씨앗·골드·햇빛·구매 배경도 이어 간다.
- 기존 규칙 작물과 새 규칙 작물이 함께 자라는 동안 각 화분은 자신의 규칙으로 계산하고 화면에 구분 표시한다.

타이쿤은 저장 v6으로 도입했으며, 새 작물의 규칙 ID는 `tycoon-v1`이다. 작물에 물/분무 남은 대기시간·횟수·비료 사용량·사용 상한을 저장하고, 정원에 비료 보유량·공통 보상 남은 대기시간·최근 지급 판 ID를 저장한다. 화분 구매 이력은 보유 화분 목록으로 유지하며 최대 네 개를 검증한다. v5 작물에는 새 필드를 0으로 추가하면서 기존 규칙·가격·성장을 보존한다. v5 원문은 `garden.json.v5-migration.bak`에 별도 보관한다. 현재 v7은 화분 스킨 소유·적용 필드만 추가하며 v6 원문은 `garden.json.v6-migration.bak`에 보관한다. 기존 재배·재화와 이전·손상·미래 버전 보호를 유지한다.

휴가에서는 성장, 반복 돌봄 대기시간, 미니게임 보상 대기시간을 함께 정지한다. 미니게임은 연습만 가능하다. 복귀 시 휴가 동안의 보상을 소급 지급하지 않는다. 일반 오프라인에서는 기존 성장 상한 72시간을 유지하고 물·분무·미니게임은 각각 다음 기회 한 번까지만 준비한다.

개발자 `+6시간`은 테스트 정원의 성장·돌봄·햇빛·보상 대기시간을 함께 진행한다. 비료를 자동 지급하지 않으며, 실제 미니게임 성공과 비료 사용은 따로 해야 한다. 정원 모드 전환이나 종료는 진행 중인 미니게임을 취소하고 보상을 다른 저장으로 옮기지 않는다.

## 8. 구현 순서와 완료 기준

1. 최대 네 화분의 구매·독립 성장·양 끝에서 멈추는 슬라이드, 새 돌봄 규칙과 작물별 시계·기존 저장 전환.
2. 물주기·분무 반복 버튼과 성장 단축, 준비 시간 표시.
3. 비료 재고·선택 화분 사용·사용 상한·저장 실패 복원.
4. 미니게임 3라운드·실전/연습 구분·성공 보상과 대기시간.
5. 저장 이전, 일반/개발자 정원 분리, 320·384·520px UI와 실제 Windows 입력 확인.
6. 네 화분 플레이 결과를 보고 최대 여섯 화분·일괄 돌봄 등 후속 편의 기능 검토.

검증할 주요 상황:

- 30분·15분 직전/정각/직후, 한 시간 뒤에도 행동 한 번씩만 가능한지.
- 첫 물·반복 물·첫 분무·반복 분무의 효과와 판매 보너스 중복 방지.
- 비료 10분 단축, 잔여 7분 개화, 튜토리얼·빈 화분·개화·휴가·기존 규칙 작물 사용 차단.
- 비료 사용이 물·분무·햇빛·미니게임 시각을 앞당기지 않는지.
- 미니게임 더블클릭·키 반복·시간 초과·실패·취소·창 전환·중복 성공 처리.
- 보상 재고 상한·작물별 사용 상한·보상 대기시간의 재실행 유지.
- 저장 실패 시 보상·대기시간·비료·성장·화분 구매의 원복과 중복 지급·차감 방지.
- 기존 두 화분의 꽃·고정 가격·구매 배경 보존과 추가 화분의 순차 개방.
- 여러 화분의 독립 성장·대기시간, 화분 선택을 바꿔도 돌봄 기회가 초기화되지 않는지.
- 공용 비료가 선택 화분 하나에만 적용되고 화분 수만큼 보상이 중복되지 않는지.

첫 플레이 조정에서는 화분 수별 하루 돌봄 횟수, 미니게임 성공·재도전 횟수, 실제 개화 시간, 시간당 골드 수익과 다음 화분 구매까지의 시간을 기록한다. 짧은 재배 간격이 별꽃만 반복하는 선택으로 고정되는지, 여러 화분을 관리하는 입력이 부담스러운지, 비료 10분의 체감이 품종마다 적절한지 관찰한다.

## 9. 경제 검토와 확장 속도

### 품종 선택의 역할

현재 카탈로그를 기준으로 첫 분무 보너스까지 받은 꽃을 판매하면 아래 순이익이 남는다. 수확 때마다 씨앗을 다시 구매하는 비용을 포함한다. 첫 무료 씨앗·튜토리얼 보상·정원에 남기는 꽃은 이 비교에서 제외한다.

| 품종 | 씨앗 | 분무 후 판매 | 한 번의 순이익 | 기본 성장 기준 화분당 시간당 순이익 |
| --- | ---: | ---: | ---: | ---: |
| 별꽃 | 8G | 13G | 5G | 약 1.67G |
| 데이지 | 20G | 55G | 35G | 약 1.46G |
| 튤립 | 35G | 110G | 75G | 약 1.56G |

시간당 순이익은 `한 번의 순이익 ÷ 기본 성장 시간`이다. 첫 물·첫 분무·수확·재파종을 제때 하고 튤립도 정상 속도로 자란다는 비교 기준이며, 실제 접속 패턴의 수익을 뜻하지 않는다. 새 튤립 규칙에는 감속이 없지만 기존 규칙의 튤립은 중간 물을 놓치면 더 오래 걸린다.

별꽃은 자주 수확하는 운영, 데이지는 하루 단위 방문, 튤립은 긴 간격의 큰 수확을 맡는다. 기존 성장 시간과 가격으로도 시간당 순이익이 비슷하므로 짧은 꽃의 판매가만 급격히 올리는 조정은 첫 적용에서 하지 않는다. 여러 품종을 함께 심는 선택을 권장하되 특정 조합을 강제하거나 조합 보너스를 추가하지 않는다.

### 화분 확장 비용의 의미

2절의 구매 비용으로, 현재 보유 화분을 모두 별꽃 판매에 사용한다고 가정한 자금 축적 시간을 계산했다. 계산은 구매에 쓸 골드 0G에서 시작하고 시간당 순이익을 환산하며, 시작용 씨앗은 이미 보유한 것으로 가정한다. 실제 수확의 3시간 단위, 시작 잔액, 무료 씨앗, 성장 단축, 정원 보관은 반영하지 않았다.

| 구매할 화분 | 구매 비용 | 수익을 내는 기존 화분 | 기본 성장 기준 자금 축적 시간 |
| --- | ---: | ---: | ---: |
| 2번 | 150G | 1개 | 90시간 |
| 3번 | 200G | 2개 | 60시간 |
| 4번 | 300G | 3개 | 60시간 |
| 5번 | 450G | 4개 | 67.5시간 |
| 6번 | 650G | 5개 | 78시간 |

따라서 두 화분에서 네 화분까지는 이 기준으로 약 120시간, 즉 5일 분량의 순이익이 필요하다. 반복 돌봄은 이를 줄이지만, 개화 후 수확하지 않는 시간과 정원에 남기는 꽃은 늘린다. **현재 비용안은 며칠 단위 확장 기획이다. 하루 안에 네 화분을 얻는 속도로 안내하지 않는다.**

화분 구매 화면에는 `보유 2/4 · 다음 화분 200G · 부족 35G`처럼 현재 단계와 부족액을 표시한다. 구매 후 남는 골드와 보유 씨앗도 함께 보여준다. 씨앗 재고가 없고 구매 후 8G도 남지 않는다면 `다음 씨앗을 살 골드가 부족해요`를 표시하되, 정상 구매 조건을 만족한 거래를 새 조건으로 차단하지 않는다.

첫 네 화분 플레이에서 2개에서 4개까지 걸린 실제 일수를 확인한다. 초기 관찰 목표는 4~7일을 제안하며, 일상적인 방문에서 7일을 넘거나 진행 정체가 보고되면 3·4번 가격부터 낮추는 안을 검토한다. 이 목표는 보장 수치가 아니며, 현재 사용자 데이터로 확인된 결과도 아니다. 보상 재화·출석 보상·새 품종을 동시에 추가하여 원인을 흐리지 않는다.

### 돌봄·비료의 성장 계산 예

별꽃에 첫 물과 첫 분무를 0분에 주고, 이후 준비된 물·분무를 매번 즉시 사용하는 경우를 계산했다. 매 시점에 자연 성장을 먼저 반영하고, 물을 적용한 뒤 아직 성장 중이면 분무한다. 비료는 미리 보유하여 첫 분무 직후 사용하는 조건이다. 미니게임을 기다리며 만드는 일반적인 플레이의 예상 시간은 아니다.

| 시작할 때 사용한 비료 | 해당 조건의 개화 시각 |
| --- | ---: |
| 0개 | 첫 물 이후 154분 |
| 1개 | 첫 물 이후 148분 |
| 4개 | 첫 물 이후 120분 |

비료 1개의 **사용 시점 효과는 항상 남은 성장 10분 단축**이다. 그러나 수확이 빨라지면 나중의 반복 돌봄 횟수도 줄어들어, 비료를 쓰지 않은 운영과 최종 개화 시각을 비교한 차이가 항상 10분인 것은 아니다. 물·분무가 동시에 준비된 때도 먼저 적용한 행동으로 개화하면 뒤의 행동은 실행하지 않는다.

비료 10분은 기본 성장 대비 별꽃 약 5.56%, 데이지 약 0.69%, 튤립 약 0.35%다. 긴 품종에서는 작은 시간 보상이라는 점을 정확히 표시한다. 사용 전에 `남은 25분 → 15분`처럼 실제 선택 화분의 결과를 보여주고, 품종에 따라 효과를 임의로 늘리거나 판매 보너스로 바꾸지 않는다.

위 순이익·확장 자금·비료 상한 4/36/72개와 별꽃 개화 시각은 2026-09-16에 카탈로그와 제안 규칙으로 검산했다. 구현 후에도 새 모델로 0·1·4개 비료 사용 시 154·148·120분 개화를 자동 검사한다.

## 10. 방문 흐름과 돌봄 부담

### 선택 보상을 받을 수 있는 최대 빈도

물 30분·분무 15분이므로 계속 성장 중인 화분 하나는 한 시간에 반복 물 2회와 분무 4회까지 준비된다. 초기 행동·수확·재파종·화분 이동·미니게임은 별도다.

| 동시에 돌보는 화분 | 시간당 반복 돌봄 최대 빈도 |
| --- | ---: |
| 1개 | 6회 |
| 2개 | 12회 |
| 4개 | 24회 |
| 6개 | 36회 |

이 수치는 모든 보상을 받으려는 운영의 입력 부담이며, 정상 성장에 필요한 횟수가 아니다. 6개 개방은 네 화분에서의 부담을 먼저 확인한 뒤 진행한다. 화분 증가에 맞춰 미니게임 보상 횟수까지 늘리지 않는다.

### 권장 짧은 방문

하루 2~4회, 한 번 30~45초의 보통 방문을 초기 사용성 목표로 제안한다. 보통 방문은 성장 중인 꽃의 확인과 선택 돌봄 기준이며, 모든 화분을 수확·재파종하는 방문까지 이 시간 안에 끝난다고 보장하지 않는다. 미니게임 매 방문 참여나 15분마다의 접속도 요구하지 않는다.

1. 준비 요약으로 첫 물이 필요한 꽃과 개화한 꽃을 확인한다.
2. 새로 심은 꽃은 첫 물을 준다. 개화한 꽃은 수확하고 보관·판매 중 원하는 처리를 한다.
3. 성장 중인 꽃의 첫 분무를 우선하고, 여유가 있으면 준비된 반복 물·분무를 사용한다.
4. 미니게임 보상이 준비됐고 더 놀고 싶을 때만 한 판을 한다.
5. 비료는 원하는 성장 중 화분에 사용한다. 짧은 꽃 우선 사용은 추천이며 자동 배분하지 않는다.

네 화분에서 관리 입력이나 이동이 부담스럽다는 관찰이 반복되면, 여섯 화분 개방 전에 준비된 화분에 대한 일괄 물·일괄 분무를 검토한다. 검토 시에도 화분별 대기시간과 한 번 준비 상한을 지키고, 전체 저장 실패 복원 규칙을 먼저 정의한다. 이번 첫 적용에는 일괄 실행을 넣지 않는다.

### 두 시간 뒤 돌아온 예

09:00에 새 규칙 꽃 네 개의 첫 물·첫 분무를 완료하고 11:00에 돌아왔다고 가정한다. 아직 개화하지 않은 각 화분에는 물 1회와 분무 1회가 준비되며, 전체 최대 8회의 돌봄만 사용할 수 있다. 네 번의 분무나 두 번의 물이 화분마다 쌓이지 않는다.

11:00의 반복 물·분무를 성공적으로 사용하면 그 화분의 다음 물은 11:30, 분무는 11:15부터 준비된다. 화분을 늦게 확인해도 기존 꽃은 기본 속도로 성장한다. 새 규칙의 꽃에는 방치 감속·시듦·품질 하락을 적용하지 않는다.

## 11. 미니게임 보상과 시간 처리의 경계

### 실전·연습 판정

판을 시작할 때 현재 정원의 보상 가능 여부, 비료 빈자리, 튜토리얼 해금, 휴가 상태를 확인하고 실전 또는 연습으로 표시한다. 연습으로 시작한 판은 도중에 대기시간이 끝나도 실전으로 바뀌지 않는다. 대기시간 종료 후 다음 판부터 실전으로 시작한다.

실전 성공을 처리할 때도 같은 정원인지와 보상 조건을 다시 확인한다. 판마다 식별자를 하나 사용하고, 이미 처리한 성공 입력에는 두 번째 보상을 주지 않는다. 재고·대기시간·지급 식별자를 하나의 저장에 함께 반영한다. 성공 결과가 저장되기 전에는 비료 획득 효과를 보여주지 않는다.

| 완료 상황 | 보상·다음 판 처리 |
| --- | --- |
| 실전 성공, 저장 성공 | 비료 +1, 공통 보상 대기 30분 시작 |
| 실전 실패·취소 | 보상 없음, 대기시간 없음, 재도전 가능 |
| 연습 성공 | 보상 없음, 기존 대기시간 유지 |
| 성공 결과 중복 입력 | 추가 지급·대기시간 재설정 없음 |
| 비료 재고가 완료 전에 상한에 도달 | 지급·대기시간 변경 없음, 이유 표시 |
| 성공 저장 실패 | 재고·대기시간·지급 기록 복원, 오류 표시 후 재도전 가능 |
| 일반/개발자 정원 변경·휴가 진입 | 진행 중 판 취소, 다른 정원으로 결과 이전 없음 |

초기 판정 구간은 30%, 3라운드 중 2회 성공을 그대로 제안한다. 초보자의 첫 세 판 안 성공 여부와 결과 화면까지 걸린 시간을 관찰하며, 너무 어렵다면 입력 속도와 구간 너비부터 조정한다. 난이도 조정이 비료 단축량·공통 대기시간·화분별 중복 지급에 영향을 주지는 않는다. 목표 구간은 색 외에도 경계선과 텍스트로 구분하고, 키보드 조작 방법을 시작 화면에 표시한다.

### 시간의 구분

- 성장·돌봄·보상 대기: 정원 경과 시간 계산을 사용한다. 휴가 때 멈추고 일반 오프라인은 다음 기회 한 번만 준비한다. 각 대기시간을 0 미만으로 누적해 추가 사용 횟수로 만들지 않는다.
- 미니게임 라운드: 실행 중 단조 증가 시계를 사용한다. 컴퓨터 날짜 변경과 개발자 `+6시간`의 영향을 받지 않는다. 앱 포커스를 잃으면 판을 취소한다.
- 비료: 선택한 작물 성장량에만 600초를 더한다. 대기시간과 정원 시각은 변경하지 않는다.

저장 실패 후 재시도하는 돌봄은 실제 현재 시각까지의 자연 성장을 다시 계산한다. 실패했던 성장 보상을 미리 남겨 두거나, 시간을 되돌려 같은 보상을 두 번 적용하지 않는다. 화면 효과와 수량은 저장 성공 상태에 맞춘다.

## 12. 첫 적용 범위와 플레이 확인표

첫 적용은 **최대 네 화분, 양 끝에서 멈추는 슬라이드, 전체 준비 요약, 반복 돌봄, 공용 비료, 미니게임 한 종류**로 묶는다. 기본 화분은 한 개이며 이후 순차 구매한다. 여섯 화분, 일괄 돌봄, 직원·자동 급수, 주문·출석 보상은 첫 범위에 포함하지 않는다. Windows 실행 파일은 v0.4.0에 포함한다.

개발자는 기존 저장의 재배 중 꽃과 새 규칙 꽃이 동시에 있는 경우도 확인한다. 기존 작물에는 반복 돌봄 준비 수나 비료 사용 가능 표시를 잘못 적용하지 않으며, 수확 이후 새 작물을 심으면 새 규칙으로 바뀐다.

첫 관찰은 네 화분으로 최소 7일 진행하는 것을 제안한다. 아래 값은 사용자가 체험 중 기록하는 로컬 관찰 항목이며, 서버 수집 기능을 추가하는 요구가 아니다.

| 확인 항목 | 기록할 내용 | 조정 기준 제안 |
| --- | --- | --- |
| 짧은 방문 | 시작부터 종료까지 시간, 화분 이동·돌봄 입력 수 | 보통 방문이 45초를 자주 넘으면 준비 요약·버튼 배치 개선 |
| 확장 속도 | 2개에서 3개, 3개에서 4개까지 실제 일수 | 전체가 7일을 넘고 정체감을 보이면 3·4번 가격 우선 검토 |
| 품종 선택 | 심은 횟수·수확 시각·판매/보관 여부 | 별꽃만 선택되는 이유가 수익인지 방문 습관인지 구분 |
| 비료 체감 | 사용 품종·횟수·사용 전후 남은 시간 | 10분 단축을 정확히 이해했는지, 긴 품종에서 유용한지 확인 |
| 미니게임 부담 | 성공·실패·재도전 수, 결과까지 시간 | 초보자가 첫 세 판 안에 성공하지 못하는 경우가 많으면 속도·구간 조정 |
| 방치와 복귀 | 2시간·하루 뒤 남은 성장, 준비 횟수 | 새 작물의 감속·시듦·보상 누적·시간 역행이 없어야 함 |
| 보관 선택 | 남긴 꽃 수, 부족한 골드, 햇빛 수집 횟수 | 꾸미기 때문에 확장이 막히는지 확인하고 골드 경제부터 조정 |

수치 변경은 다음에 심는 작물부터 적용한다. 이미 심은 작물의 기본 성장 시간·판매가·규칙·비료 상한과 이미 구매한 화분의 소유권은 보존한다. 플레이 결과가 나오기 전까지 4~7일 확장, 방문 시간, 미니게임 난이도는 **검증 전 목표값**으로 표시한다.

첫 적용은 Python 모델·저장·화면에 연결했다. 기존 85개 검증에 타이쿤 시간 경계·비료·보상·이전·Qt 입력 검증을 추가하고 320·384·520px의 성장·빈 화분 화면과 미니게임을 확인한다. 실제 사용자의 방문 습관·경제·난이도 검증은 별도의 7일 플레이 관찰 대상이며, 여섯 화분·일괄 돌봄·실행 파일 배포는 후속 범위로 둔다.
