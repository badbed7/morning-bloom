# v0.1 검증 기록

검증 환경: Linux, Godot 4.7.2 stable 공식 바이너리.

## 완료

- Godot 프로젝트 가져오기 및 모든 GDScript 파싱.
- 게임 상태·저장 자동 검증 36개 통과: 시간 누적, 시간 역행, 72시간 상한, 유예 경계, 회복, 휴가, 중복 수확·판매, 최초 튜토리얼 1회, 저장 복원, 백업 복구, 미래 스키마 덮어쓰기 금지 등.
- UI 스모크 테스트 통과: 실제 씬을 생성하여 심기·물주기·데모 시간 이동·보관·판매·저장 호출, 420px 홈 최소 크기 및 설정 스크롤 범위 확인.
- 실제/데모/통합 테스트 저장 파일 분리. JSON 복원 시 재화·씨앗 등 정수 필드의 타입 정규화 보완.

## 아직 확인하지 못한 항목

- 이 실행 환경에서 디스플레이 서버를 열 수 없어 실제 창의 스크린샷·시각 검증은 완료하지 못했습니다.
- 실제 Windows의 투명도, 다중 모니터, OS 배율, 최상단 표시와 포커스 동작.
- Windows 실행 파일 내보내기, 코드 서명, 장시간 성능 측정.
- GitHub Actions 실제 실행: 저장소 생성·업로드 이후 확인해야 합니다.
- `publish-github.ps1`은 제공용 스크립트이며 실제 GitHub 인증/생성/업로드는 실행하지 않았습니다.

이 기록은 테스트를 실행한 범위만 의미합니다. Windows 검증 방법은 development.md를 따릅니다.
