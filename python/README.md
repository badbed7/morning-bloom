# Morning Bloom Python 2D 초안

Python 3.11~3.12와 PySide6 6.8.3을 사용하는 Windows 우선 데스크톱 게임입니다.

## Windows 실행

1. Python 3.12 **64비트**를 설치합니다(Python Launcher 포함).
2. 저장소 전체를 내려받고 압축을 풉니다.
3. 루트의 `run-python.bat`을 더블클릭합니다. 첫 실행은 인터넷에 연결해 전용 `.venv-py312` 환경을 만듭니다.

`PySide6==6.8.3`은 Python 3.14 이상을 지원하지 않습니다. 설치 오류가 나면 `py -0p`에서 Python 3.12 64비트가 보이는지 확인하고 최신 `run-python.bat`을 사용하세요.

직접 실행:

```powershell
cd python
py -3.12 -m venv .venv-py312
.venv-py312\Scripts\python.exe -m pip install -r requirements.txt
.venv-py312\Scripts\python.exe -m morning_bloom
# 별도 저장과 설정의 +6시간 버튼을 쓰는 개발자 모드
.venv-py312\Scripts\python.exe -m morning_bloom --demo
```

## 타이쿤 첫 적용 구현 범위

- 별꽃 3시간(씨앗 8G·판매 12G), 데이지 24시간(20G·50G), 튤립 48시간(35G·100G)
- 모든 꽃은 첫 물주기 뒤 성장 시작
- 새 재배는 물 30분·분무 15분 대기 후 반복 돌봄 가능, 늦게 돌봐도 기본 속도로 성장
- 첫 물은 성장 시작, 반복 물은 성장 -3분, 매 분무는 성장 -1분
- 첫 분무만 판매가 10% 보너스(별꽃 13G·데이지 55G·튤립 110G)
- 업데이트 전에 심은 꽃은 옛 규칙 유지: 튤립은 22시간 미리 물, 24시간 권장, 30시간부터 미급수 시 50% 성장
- 첫 데이지 60초 튜토리얼과 첫 수확 씨앗 1개 보상
- 상점, 시각적 꽃 정원, 최대 네 화분의 독립 재배와 전체 돌봄 준비 요약
- 2·3·4번 화분을 150G·200G·300G에 순차 구매
- 3라운드 타이밍 미니게임, 2회 이상 성공하면 비료 1개
- 공통 보상 대기 30분, 재고 상한 10개, 대기·휴가·상한 중에는 연습 가능
- 비료 1개로 선택 화분의 성장 -10분, 작물당 기본 성장의 25% 이내 사용
- 정원 꽃 1개당 20분마다 햇빛 1개 생산, 클릭 수집과 대기 상한 9개
- 햇빛 전용 꾸미기 상점과 크림·하늘·라벤더 정원 배경 구매·적용
- 72시간 오프라인 상한, 휴가 중 성장·돌봄 정지
- 개체별 규칙·가격 고정, v1~v5 저장의 v6 자동 이전과 이전본 전용 백업
- 행동 직후·30초마다·종료 시 원자적 저장, 정상 백업, 손상·미래 버전 보호

휴가 중에는 심기·물주기·분무·비료 사용·미니게임 보상이 잠기고 모든 대기시간이 멈춘다. 이미 핀 꽃의 수확과 상점 구매, 정원 판매는 계속 가능하다. 새 재배는 [타이쿤 기획](../docs/tycoon-care-fertilizer.ko.md), 이전에 심은 꽃은 [v0.4 규칙](../docs/game-design-v0.4.ko.md)을 따른다.

## 비료 사용과 미니게임

첫 꽃을 정원에 보관하면 화분 화면의 비료 도구가 열린다. `비료 만들기`에서 시작 버튼을 누르고 움직이는 표시를 목표 구간에서 멈춘다. 클릭 또는 스페이스 키를 사용하며 각 라운드는 최대 4초다. 3번 중 2번 성공하면 비료가 한 개 늘고, 다음 실전 보상은 30분 뒤에 열린다. 실패·취소에는 비용과 대기시간이 없다. 다른 앱으로 전환하면 진행 중인 판은 취소한다.

성장 중인 새 규칙 꽃을 선택하고 `비료 -10분`을 누르면 비료 한 개를 소모한다. 남은 시간이 10분 미만이면 즉시 개화한다. 사용 전 도움말에 결과와 작물별 사용 상한을 표시한다. 별꽃 최대 4개, 데이지 36개, 튤립 72개이며 비료는 공용 재고다. 빈 화분·첫 물 이전·개화한 꽃·기존 규칙 꽃에는 사용할 수 없다. 비료가 다른 화분이나 돌봄·햇빛·미니게임 시계를 앞당기지 않는다.

화분 화면은 빈 화분에 씨앗 선택·심기, 성장 중에는 물·분무·비료, 개화 후에는 정원 보관 버튼을 보여준다. 비료 재고와 만들기는 하단의 공용 도구 영역에 표시한다. 미니게임은 본체와 같은 불투명도·최상단 설정으로 열리며, 본체의 불투명도를 바꾸면 함께 반영한다. 제목을 잡아 이동하고 닫기 버튼 또는 Esc로 취소한다. 라운드별 성공·놓침을 표시하고 완료 후 정원으로 돌아간다.

정원에 보관한 꽃은 공통 20분 시계마다 꽃당 햇빛 하나를 만든다. 미수집 햇빛은 최대 9개이며 사라지지 않는다. 빛을 클릭하면 햇빛 재화가 1 증가한다. 햇빛은 정원 배경 꾸미기에만 사용하고 골드·성장 능력치와 교환하지 않는다. 첫 꽃을 보관하면 수집 방법을 알 수 있도록 햇빛 하나가 즉시 생긴다.

## 정원·메뉴

상단 `‹ 화분 ›`의 화살표로 화분 → 상점 → 정원 → 화분을 순환한다. 설정은 오른쪽 아래 버튼에서 별도로 열며 돌아가면 직전 화면이 복원된다.

재배할 화분도 드롭다운 대신 `‹ 화분 1 / 2 · 데이지 ›`의 좌우 화살표로 넘긴다. 선택한 화분의 그림과 돌봄 화면이 가로로 슬라이드하며 마지막 화분 다음에는 첫 화분으로 돌아온다. 화분이 하나면 화살표를 비활성화하고, 상점에서 두 번째 화분을 구매하면 활성화한다. 마지막 선택은 저장되어 재실행해도 유지된다. 씨앗 품종 선택은 기존 드롭다운을 사용한다.

`정원 보관`한 꽃은 초록 잔디 위에 꽃 화분 그림으로 표시된다. 꽃을 가리키면 판매가를 확인할 수 있고, 아래 돈주머니 영역까지 드래그해 놓으면 해당 꽃만 판매한다. 영역 밖에 놓거나 취소하면 팔리지 않는다. 씨앗 수량과 심기는 화분 화면에서 확인한다. [수정 기획·예외 처리·검증 결과](../docs/garden-ui-revision.ko.md).

## 개발자 모드와 +6시간

1. 오른쪽 아래 `설정`을 열고 아래로 스크롤한다.
2. `개발자 모드 · 별도 테스트 정원`을 켠다. 첫 진입은 새 테스트 정원, 이후는 기존 테스트 저장을 연다.
3. `시간 +6시간`을 누른다. 모든 화분과 돌봄·햇빛·비료 보상 대기시간에 반영하고 저장한다. 비료를 자동 지급하거나 미니게임 성공을 만들지는 않는다. 첫 물주기 전에는 자라지 않으며 휴가 중에는 모든 성장·돌봄·보상 대기시간이 정지한다.
4. 개발자 모드를 끄면 원래 일반 정원으로 돌아간다.

일반 정원의 꽃·재화에 테스트 결과를 합치지 않는다. 일반 정원에는 실제 경과 시간만 적용하며, OS 시각은 변경하지 않는다. 저장 실패 시 시간 이동도 되돌린다. 다른 창이 전환 대상 정원을 사용 중이면 전환하지 않는다. `--demo`로 실행해도 같은 개발자 모드가 열린다.

앱을 일반 실행하면 항상 일반 정원을 연다. 테스트 저장 시각이 실제보다 앞선 경우, 다시 테스트 정원을 열면 마지막 테스트 시각에서 이어 가도록 보정한다. 이때 종료 중 실제 경과 시간을 별도로 더하지는 않는다.

## 저장 위치

Qt `AppLocalDataLocation` 아래 `MorningBloomPython` 폴더를 사용합니다. Windows에서는 보통 `%LOCALAPPDATA%\MorningBloomPython`입니다.

- `garden.json`: 일반 게임
- `demo-garden.json`: 개발자 모드의 별도 테스트 정원
- `*.json.bak`: 직전 정상 저장
- `*.json.v3-migration.bak`: v1~v3에서 처음 이전할 때의 원문
- `*.json.v5-migration.bak`: v5에서 v6으로 처음 이전할 때의 원문

손상된 본 파일은 정상 백업으로 복구합니다. 양쪽이 모두 손상되거나 더 높은 저장 버전이면 시작과 저장을 멈춰 원본을 보존합니다.

## 검증

```powershell
cd python
$env:QT_QPA_PLATFORM = 'offscreen'
.venv-py312\Scripts\python.exe -m unittest discover -s tests -v
```

테스트는 기존 성장·급수 규칙, 저장 이전·복구, 메뉴·화분 슬라이드, 드래그 판매, 햇빛·배경, 개발자 모드에 더해 네 화분 구매, 반복 돌봄 경계, 비료 단축·사용 상한, 실전/연습, 보상 대기·중복 방지·실패 복원, 키보드 입력·시간 초과·포커스 취소를 검사합니다. 320·384·520px에서 성장·빈 화분·첫 물·개화·튜토리얼 화면을 확인합니다. 미니게임의 투명도 동기화·Esc·결과 화면을 자동 검증하며, Windows 네이티브 창에서도 본체와 미니게임의 알파값이 같은지 확인했습니다. 실제 데스크톱 합성 화면, 창 이동, 배율과 다중 모니터는 수동 점검 대상입니다.

## 다음 범위

[햇빛 수집·정원 꾸미기](../docs/sunlight-interaction.ko.md)의 첫 범위를 구현했습니다. 생산 간격·대기 상한·배경 가격은 플레이 관찰 후 조정할 수 있습니다. 개발자 모드의 `+6시간`으로 재배와 햇빛 생산을 함께 시험할 수 있습니다.

EXE 빌드·릴리스 게시·자동 업데이트 배포는 보류합니다. 다섯·여섯 번째 화분과 일괄 돌봄은 네 화분 플레이 관찰 이후 검토합니다. 화분 스킨·정원 소품, 별꽃 정식 이름·아트, 온도, 장식장·꽃꽂이, 트레이·OS 알림도 후속 작업입니다. 현재 꽃과 햇빛 그림은 QPainter 도형 시제품입니다.
