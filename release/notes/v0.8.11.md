# Morning Bloom 0.8.11

PR #9의 수집·바람놀이·설정 및 Google Drive 오류 처리 개선을 배포합니다.

## 신규 128종 획득·사용 및 영구 도감

- 식물 22종 / 정원 83종 / 화분 45종, 총 150종을 도감에서 확인합니다.
- 꽃길 뽑기에 식물 분류를 추가했습니다. 신규 식물 8종은 최초 획득 시 영구 재배 해금과 씨앗 1개를 받으며, 해금 후 골드로 씨앗을 재구매합니다.
- 신규 정원 79종·화분 41종을 뽑기로 획득하고 실제로 적용할 수 있습니다. 새 항목은 뽑기 전용이며, 기존 일반 상점 경로와 로즈 소유권은 유지합니다.
- 식물의 개화 발견 이력은 판매 후에도 남습니다. 재배 해금·발견·보유·사용 상태를 구분합니다.
- 기존 60칸·주사위 2개·햇빛 결제와 보장을 유지합니다. 보상 풀 확장으로 로즈와 기존 라벤더 정원의 개별 당첨률은 낮아집니다. [전체 등급표](https://github.com/badbed7/morning-bloom/blob/v0.8.11/docs/collection-items.ko.md)와 [확률·수집 비용 분석](https://github.com/badbed7/morning-bloom/blob/v0.8.11/docs/issue-resolution-2026-11-03.ko.md)을 참고하세요.

## 홀씨 바람놀이 강화

- 누르기를 놓아도 공중에서 전진하는 동안 진행도가 쌓입니다. 바닥·일시정지·창 비활성 시 정지합니다.
- 골드로 이동 속도 0~10단계와 고리 골드 보상 0~5단계를 강화합니다. 구매 전에 가격과 현재·다음 효과를 표시합니다.
- 민들레 1송이·햇빛 1개 완료 보상과 저장된 기존 강화 단계를 유지합니다.

## 뽑기 문구·개발자 모드·바탕화면 꽃

- 뽑기 제목의 불필요한 총 칸 수를 제거하고 진입 버튼을 ‘주사위 굴리기’로 정리했습니다.
- 별도 테스트 정원에 무한 햇빛 토글을 추가했습니다. 테스트 뽑기·일반 햇빛 구매는 햇빛과 무료권을 차감하지 않으며 일반 정원에는 적용하지 않습니다.
- 설정에서 바탕화면 꽃 크기를 50~200%, 10% 단위로 조절합니다. 그림·창·클릭 영역을 함께 조절하고 선택값을 저장합니다.

## Google Drive 오류 대응

- 실패 단계와 HTTP/OAuth/Drive 오류 코드를 안내합니다. 인증 만료·클라이언트 변경은 재연결 필요로 전환하고 반복 자동 재시도를 중지합니다.
- 일시적 오류는 제한 재시도하고, 영구 설정 오류는 자동 백업을 중지합니다. 브라우저 열기 실패·로그인 취소·대기 만료 안내를 구분합니다.
- 종료 백업 실패 시 로컬 정원과 미동기화 표식을 보존하며, 모든 오류에 무조건 재연결을 요구하지 않습니다.
- 기존 신고의 실제 Google 계정 오류 원인·복원 검증은 [#8](https://github.com/badbed7/morning-bloom/issues/8)에서 계속 추적합니다.

## 저장·업데이트 안내

- 기존 저장을 schema 15로 자동 이전하고 꽃·재화·꾸미기·배치·가챠 이력을 보존합니다. 이전 저장 백업을 남깁니다.
- 게임을 종료한 뒤 기존 `run-python.bat` 또는 `MorningBloom.exe` 런처로 다시 실행하면 업데이트를 확인합니다.
- 기존 런처에서 업데이트가 적용되지 않으면 아래 ZIP을 새 폴더에 전체 압축 해제하고 그 폴더의 BAT/런처를 실행하세요. 저장 폴더는 지우지 마세요.
- 실행 중 백그라운드 업데이트와 자동 재시작은 [#10](https://github.com/badbed7/morning-bloom/issues/10)의 후속 기획이며 이번 버전에는 포함하지 않습니다.

## 다운로드

- **Python-BAT:** `MorningBloom-0.8.11-Python-BAT.zip` 전체 압축 해제 후 `run-python.bat` 실행. Python 3.12 64비트가 필요합니다.
- **Windows EXE:** `MorningBloom-0.8.11-Windows-x64.zip` 전체 압축 해제 후 `MorningBloom.exe` 실행. Python 설치가 필요 없습니다.
- `MorningBloom-python.zip` / `MorningBloom-game.zip`과 JSON 파일은 자동 업데이트용입니다.

Windows CI의 게임·업데이터 검사와 EXE/Python-BAT 패키지의 격리 시작 검사를 거쳐 게시합니다. 실제 Google 계정 로그인·복원과 Windows 혼합 DPI·다중 모니터 실기는 자동 검사와 별도로 확인해야 합니다.
