# Morning Bloom 0.8.12

이슈 #10의 실행 중 업데이트 확인·백그라운드 다운로드·저장 후 자동 재시작을 추가합니다.

## 처음 한 번은 새 ZIP으로 런처를 교체하세요

**v0.8.12 Python-BAT 또는 Windows-x64 ZIP을 새 폴더에 전체 압축 해제하고, 해당 폴더의 BAT/런처로 실행하세요.** 기존 런처 파일 자체는 게임 자동 업데이트로 교체되지 않습니다. 이전 런처로 게임만 업데이트하면 새 기능이 비활성화되고 교체 안내가 표시됩니다. 기존 정원 저장 폴더는 지우지 마세요.

## 실행 중 업데이트

- 게임이 켜져 있는 동안 5분마다 새 공개 버전을 확인합니다. 설정에서 ‘업데이트 확인’으로 수동 확인할 수 있습니다.
- 플레이를 유지하면서 새 버전을 별도 폴더에 다운로드하고 파일·실행 검사를 진행합니다.
- ‘업데이트 준비 완료’ 알림의 **지금 적용**을 누르면 정원을 저장하고 정상 종료한 뒤 새 버전으로 자동 실행합니다.
- **나중에**를 누르면 현재 게임을 계속 플레이하며 설정에서 다시 적용할 수 있습니다. 준비한 파일은 다음 실행에도 재사용합니다.
- 가챠 결과·꽃·재화·배치·설정과 일반/개발자 정원 선택을 보존합니다. 이번 기능으로 저장 schema는 변경하지 않습니다.

## 실패 처리

- 저장 또는 종료 확인 실패 시 적용을 취소하고 현재 게임을 유지합니다.
- 실제 게임 프로세스가 종료되기 전에는 버전을 전환하거나 새 게임을 실행하지 않습니다.
- 활성화 직전 정원 파일을 별도 백업합니다. 새 버전 시작 실패 시 저장이 그대로인 경우에만 이전 버전으로 복구합니다. 저장이 바뀌면 원본과 백업을 보존하고 구버전에 새 저장을 전달하지 않습니다.
- Google Drive 실패는 로컬 저장·미동기화 표식을 보존하며 #8에서 실제 계정 문제를 계속 추적합니다.

## 다운로드

- Python 3.12 64비트 사용: `MorningBloom-0.8.12-Python-BAT.zip` → 전체 압축 해제 → `run-python.bat`.
- Python 설치 없이 사용: `MorningBloom-0.8.12-Windows-x64.zip` → 전체 압축 해제 → `MorningBloom.exe`.

[구현·검증 상세](https://github.com/badbed7/morning-bloom/blob/v0.8.12/docs/live-update.ko.md). EXE/Python-BAT 패키지의 실제 두 게임 프로세스와 합성 후속 버전으로 재시작·저장 복원을 자동 검증합니다. 이번 배포는 재시작 없는 코드 핫 리로드를 포함하지 않습니다.
