# Morning Bloom 0.8.13

## 도감 상위 분류와 이미지 불일치 수정

- **정원 ‘저녁 라벤더 정원’**에 일반 라벤더 식물이 표시되던 오류를 수정했습니다. 실제 정원 배경 이미지로 표시합니다.
- 같은 원인으로 **화분 ‘로즈 리본’**에 장미 식물이 표시되던 오류도 수정했습니다. 실제 로즈 화분 스킨으로 표시합니다.
- 식물·정원·화분이 같은 ID를 사용하더라도 분류를 함께 확인해 올바른 이미지를 선택하고 캐시합니다.
- 도감 150종(식물 22 / 정원 83 / 화분 45)의 분류·항목 연결과 렌더링을 전수 검사했습니다. [점검 기록](https://github.com/badbed7/morning-bloom/blob/v0.8.13/docs/catalog-category-audit.ko.md).

기존 꽃·재화·꾸미기 소유권과 가챠 이력을 유지합니다. 저장 형식·확률·가격은 바꾸지 않습니다.

## 업데이트
