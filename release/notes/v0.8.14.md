# Morning Bloom v0.8.14

## 먼저: 새 런처로 교체하세요

**이번 버전은 전체 ZIP을 새 폴더에 모두 해제하고 그 폴더의 `MorningBloom.exe` 또는 `run-python.bat`으로 한 번 실행해 주세요.** 기존 게임 자동 업데이트는 런처 자체를 바꾸지 않습니다. v0.8.13을 다시 받으면 이번 SSL 수정이 적용되지 않습니다.

정원과 재화는 기존 저장을 이어서 사용합니다. `%LOCALAPPDATA%/MorningBloomPython` 저장 폴더를 삭제하지 마세요.

## 업데이트 인증서 오류 수정

- Windows에서 `CERTIFICATE_VERIFY_FAILED: unable to get issuer certificate` 때문에 최신 조회가 실패하던 경로를 Windows 네이티브 인증서 체인 검증으로 변경했습니다.
- 업데이트 정보 조회와 ZIP 다운로드에 같은 검증 방식을 적용했습니다. EXE·BAT 모두 필요한 TLS 백엔드를 포함합니다.
- 인증서·호스트 이름·HTTPS 및 ZIP 크기·SHA-256 검사를 유지합니다. 시스템이 신뢰하지 않는 인증서는 계속 거부합니다.
- `update.log`에 TLS 백엔드와 인증서 검증 코드를 기록합니다. `--diagnose-updates`로 게임 설치·저장 변경 없이 진단할 수 있습니다.
- Windows에서 중간 인증서 누락 오류를 재현하고 복구·잘못된 인증서 차단을 EXE·BAT 모두 검사했습니다. 실제 공개 업데이트 JSON·ZIP 다운로드도 검증했습니다.

## 고등급 곁길 보드 4종

| 출입구 | 곁길 | 보상 |
|---|---|---|
| 11번 | 새싹 곁길 | SR 이상, 6·12번 SSR 확정 |
| 26번 | 이슬 곁길 | SR 이상, 4·8·12번 SSR 확정 |
| 41번 | 꽃망울 곁길 | SR 이상, 3·6·9·12번 SSR 확정 |
| 56번 | 황금 곁길 | 모든 칸 SSR 확정 |

- 특수 칸에 정확히 도착하면 그 회차의 보상을 받고 다음 회차부터 12칸 전용 보드에서 뽑습니다. 통과는 진입하지 않습니다.
- 곁길에서도 주사위 2개의 합만큼 이동하며 회당 햇빛 10개입니다. 네 번 추첨한 뒤 일반 보드의 원래 출입구로 복귀합니다. 무료 추가 추첨은 없습니다.
- 10회 뽑기에서도 일반 보드·곁길·복귀를 순서대로 연출합니다. 민들레 씨는 실제 보드 경로를 따라 이동합니다.
- 식물·화분·정원 선택과 공유 천장을 유지합니다. 곁길은 기존 분류별 풀에서 R을 제외하며, 고등급 지급량이 늘어납니다.
- 보드·위치·진행 횟수·보상을 저장합니다. 이전 저장은 v16으로 이전하며 기존 재화·소유권·가챠 이력을 보존합니다. 기존 곁길 표시는 남은 횟수로 이어갑니다.

변경: PR #13, #14. 이전 도감 라벤더·로즈 분류 수정과 실행 중 업데이트도 포함합니다.
