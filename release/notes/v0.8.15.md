# Morning Bloom v0.8.15

## 홀씨 바람놀이 조작과 UI 개선

- 바람놀이 팝업의 닫기 버튼을 메인 창과 같은 텍스트 X·투명 배경·호버 스타일로 통일했습니다. 운영체제 기본 닫기 이미지는 사용하지 않습니다.
- 버튼·비행장·스페이스를 처음 누를 때 홀씨에 주는 상승 속도를 0.18에서 0.07로 약 61% 낮췄습니다. 누르자마자 위로 튀는 움직임이 완만해집니다.
- 길게 누를 때의 바람 가속, 이동 속도 강화, 고리 보상과 저장 형식은 그대로 유지합니다.

## 다운로드

- Python 없이 실행: `MorningBloom-0.8.15-Windows-x64.zip` 전체 압축 해제 후 `MorningBloom.exe` 실행.
- Python 3.12 64비트 사용: `MorningBloom-0.8.15-Python-BAT.zip` 전체 압축 해제 후 `run-python.bat` 실행.
- v0.8.14의 Windows 업데이트 인증서 수정과 고등급 곁길 보드를 포함합니다. v0.8.13 이하의 이전 런처를 사용 중이면 전체 ZIP을 새 폴더에 해제해 새 런처로 실행하세요. 기존 정원 저장 폴더는 삭제하지 마세요.
