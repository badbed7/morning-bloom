# Morning Bloom v0.8.16

## 설정에 현재 게임 버전 표시

- 설정의 개발자 도구 바로 위에 `현재 게임 버전: v0.8.16`을 표시합니다.
- 런처가 전달한 실제 실행 버전을 우선 표시합니다. 새 버전을 다운로드만 한 상태에서는 현재 실행 중인 버전을 유지하고, 적용 후 재시작하면 새 버전이 표시됩니다.
- 소스에서 직접 실행할 때는 `release/VERSION`을 읽습니다. 버전 정보가 없으면 ‘확인 불가’로 표시합니다.
- 버전 문구를 마우스로 선택해 복사할 수 있습니다.

## 다운로드

- Python 없이 실행: `MorningBloom-0.8.16-Windows-x64.zip` 전체 압축 해제 후 `MorningBloom.exe` 실행.
- Python 3.12 64비트 사용: `MorningBloom-0.8.16-Python-BAT.zip` 전체 압축 해제 후 `run-python.bat` 실행.
- v0.8.15의 바람놀이 닫기 버튼 통일 및 완만해진 초기 상승 동작을 포함합니다.
- v0.8.13 이하의 이전 런처를 사용 중이면 전체 ZIP을 새 폴더에 해제해 새 런처로 실행하세요. 기존 정원 저장 폴더는 삭제하지 마세요.
