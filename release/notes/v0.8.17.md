# Morning Bloom v0.8.17

## 곁길 추첨 2회로 변경

- 새싹·이슬·꽃망울·황금 곁길 모두 **진입 후 2회 추첨**하면 일반 보드의 원래 출입구로 복귀합니다.
- 진입 회차는 일반 보드 보상을 받고, 다음 회차부터 곁길에서 두 번 추첨합니다. 10회 뽑기도 같은 순서로 처리합니다.
- 안내 문구와 진행 표시를 2회 기준으로 맞췄습니다.
- 매회 햇빛 10개, 무료권 우선 결제, 등급 보장과 천장은 유지합니다.

## 기존 저장 이전

- 저장 형식을 v17로 이전합니다. 곁길을 0~1회 진행했다면 현재 위치에서 남은 횟수를 이어갑니다.
- 이전 저장에서 이미 2~3회를 진행했다면 추가 차감·보상 없이 일반 보드의 원래 출입구로 복귀합니다.
- 재화·보유 아이템·천장·이력을 보존합니다. 이전 로컬 저장 원본은 별도 백업하며 Google Drive 복원에도 같은 이전 규칙을 적용합니다.
- 손상된 저장은 자동으로 정상화하지 않고 거부합니다.

## 다운로드

- Python 없이 실행: `MorningBloom-0.8.17-Windows-x64.zip` 전체 압축 해제 후 `MorningBloom.exe` 실행.
- Python 3.12 64비트 사용: `MorningBloom-0.8.17-Python-BAT.zip` 전체 압축 해제 후 `run-python.bat` 실행.
- 설정의 개발자 도구 위에서 현재 게임 버전을 확인할 수 있습니다.
- v0.8.13 이하의 이전 런처를 사용 중이면 전체 ZIP을 새 폴더에 해제해 새 런처로 실행하세요. 기존 정원 저장 폴더는 삭제하지 마세요.
