# Morning Bloom v0.8.18

## 클라우드 저장 보호

- 시작·자동 백업·종료 모두 이 PC와 클라우드의 변경을 확인합니다. 미백업 로컬 진행을 과거 저장으로 자동 교체하지 않습니다.
- 다른 PC와 동시에 저장하면 각각의 백업을 보존하고 이어서 사용할 정원을 선택할 수 있습니다. 기존 저장을 덮어쓰거나 자동 삭제하지 않습니다.
- 첫 백업은 파일과 내용을 한 번에 업로드합니다. 업로드 실패·응답 유실 후에도 다음 주기에 저장을 확인해 복구합니다.
- OAuth·Drive 요청에도 Windows 기본 인증서 검증을 적용했습니다. 인증서 검증은 유지합니다.
- v0.8.17의 클라우드 저장을 불러올 수 있습니다. 새 저장 형식을 위해 사용하는 PC는 모두 업데이트하세요. 여러 백업은 저장 용량을 사용하며 이번 버전은 이전 백업을 자동 삭제하지 않습니다.

## 뽑기 결과와 희귀도 연출

- 10회 뽑기의 아이템 10개를 정산 화면에서 모아 보여줍니다. 신규·중복, 등급, 분류와 교환잎 합계를 확인할 수 있습니다.
- SR·SSR은 별도 색상·확대·입자 연출로 강조합니다. 건너뛰어도 같은 결과 화면을 보여주며 보상은 중복 지급하지 않습니다.
- 1회 뽑기도 결과 카드를 표시합니다. 확률·비용·천장·곁길 2회 규칙은 유지합니다.

## 정원·화분 선택과 씨앗 목록

- 정원 탭의 `정원 고르기`에서 보유 배경을 적용합니다.
- 빈 화분의 `심을 화분` 버튼에서 외형을 선택한 뒤 씨앗을 심습니다. 슬롯마다 다른 외형을 사용할 수 있습니다. 취소하면 씨앗을 소비하지 않습니다.
- 선택 목록은 보유 항목을 먼저 표시하고 미보유 항목은 흑백으로 표시합니다. 미보유 항목을 바로 적용하거나 자동 구매하지 않습니다.
- 심기 목록에는 보유 수량이 1개 이상인 씨앗만 표시합니다. 구매·소진 시 목록과 선택을 갱신하고 씨앗이 없으면 심기를 비활성화합니다.

## 저장 이전·설치

- 저장 형식 v18: 이전 장착 외형을 기존 화분에 이어 적용하고 꽃·재화·성장·뽑기 이력을 보존합니다. 로컬 이전 원본은 별도 백업합니다.
- EXE: `MorningBloom-0.8.18-Windows-x64.zip` 전체 압축 해제 후 `MorningBloom.exe` 실행.
- BAT: `MorningBloom-0.8.18-Python-BAT.zip` 전체 압축 해제 후 `run-python.bat` 실행. Python 3.12 64비트가 필요합니다.
- 기존 정원 저장 폴더는 삭제하지 마세요. v0.8.13 이하 런처는 전체 ZIP을 새 폴더에 풀어 새 런처를 사용하세요.
