# Morning Bloom v0.8.19

## 식물마다 화분 꾸미기

- 정원에서 식물을 클릭하면 해당 식물의 화분 선택 화면이 열립니다.
- 보유한 화분 종류와 색상을 골라 미리보기로 확인하고 `이 화분에 담기`를 눌러 적용합니다. 취소하면 기존 설정을 유지합니다.
- 같은 품종도 개체별로 꾸밀 수 있습니다. 장미 1과 장미 2에 같은 종류의 화분을 다른 색으로 적용할 수 있습니다.
- 재배 화면의 `화분 꾸미기`에서 빈 슬롯과 재배 중인 식물도 꾸밀 수 있습니다. 씨앗·재화·성장 진행은 그대로 유지합니다.
- 보유 화분이 먼저 나오고 미보유 항목은 흑백으로 표시됩니다. 미보유 화분은 적용할 수 없습니다.
- 종류를 유지하며 기본·베이지·차콜·버건디·아이보리·세이지·더스티 블루 색상을 선택할 수 있습니다.
- 선택할 때 식물이 살짝 떠올랐다 내려오는 분갈이 미리보기를 제공합니다. 320px 창에서도 목록과 적용 버튼을 사용할 수 있습니다.

## 장미·데이지 기본 색상

- 장미의 기본 토분은 짙은 자주색으로, 데이지의 기본 토분은 베이지색으로 변경했습니다.
- 꽃잎 색상과 화분 무늬·형태는 유지합니다.
- 정원·드래그 미리보기·보관 목록·플로팅·분무 화면에 개별 화분 외형을 동일하게 적용합니다.

## 저장 이전·설치

- 저장 형식 v19: 기존 식물 ID·성장·재화·화분 종류를 보존하며 개별 색상과 수확한 식물의 화분 설정을 저장합니다. 수확·재실행·클라우드 복원 후에도 유지합니다.
- 이전 저장은 자동으로 변환하며 로컬 원문을 버전별 백업으로 보존합니다. 같은 정원을 사용하는 PC는 모두 업데이트하세요.
- 적용 저장이 실패하면 원래 화분으로 되돌리고 선택 화면을 유지합니다.
- EXE: `MorningBloom-0.8.19-Windows-x64.zip` 전체 압축 해제 후 `MorningBloom.exe` 실행.
- BAT: `MorningBloom-0.8.19-Python-BAT.zip` 전체 압축 해제 후 `run-python.bat` 실행. Python 3.12 64비트가 필요합니다.
- 기존 정원 저장 폴더를 유지합니다. 기존 런처의 업데이트 기능도 사용할 수 있습니다.
