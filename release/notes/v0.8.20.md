# Morning Bloom v0.8.20

## 장미 8색과 희귀도

- 장미 꽃을 빨강·핑크·주황·하양·노랑·보라·파랑·검정의 8가지 수집 품종으로 구분합니다.
- 기존 장미 ID·보유 씨앗·재배·수확 기록은 빨강 장미로 이어집니다.
- 빨강 장미는 R 등급이며 상점에서 씨앗을 50G로 구매할 수 있습니다.
- 나머지 7종은 꽃길 뽑기의 `장미 씨앗` 분류에서 획득합니다. 획득 후에도 상점에서 구매할 수 없습니다.
- 첫 획득과 중복 모두 해당 장미 씨앗 1개를 지급합니다. 중복 교환잎은 기존 규칙을 유지합니다.
- 8종 모두 성장 3일·기본 판매 150G·분무 보너스 15G입니다. 심기·개화·재실행 때 색상을 다시 추첨하지 않습니다.

## 장미 씨앗 확률

아래 수치는 **보장 없는 일반 칸에 도착한 경우의 게임 추첨 기준**입니다. 실제 자연 개화율의 실측값이 아닙니다. 색소·육종 자료를 참고한 게임 설계값이며 파랑은 특수 육종, 검정은 흑적색 장미를 모티브로 합니다.

| 색상 | 등급 | 일반 칸 기준 |
|---|---|---:|
| 빨강 | R | 상점 전용 |
| 핑크 | R | 25% |
| 주황 | SR | 15% |
| 하양 | R | 25% |
| 노랑 | R | 20% |
| 보라 | SR | 10% |
| 파랑 | SSR | 1% |
| 검정 | SSR | 4% |

- `확률 상세`에서 현재 보드·주사위·특수 칸·천장을 반영한 다음 1회의 개별 확률을 확인할 수 있습니다.
- 곁길과 천장에 따라 확률이 달라집니다. 황금 곁길과 SSR 천장에서는 검정 80% / 파랑 20%입니다.
- 기존 등급 규칙·곁길 2회·천장·비용·무료권은 유지하며 모든 분류가 보드 진행과 천장을 공유합니다. 10회 뽑기는 회차마다 위치와 보장이 바뀝니다.
- 현실 자료와 게임 수치의 구분, 상세 근거는 `docs/rose-varieties.ko.md`에 기록했습니다.

## 화분·표시·저장

- v0.8.19의 장미·데이지 품종별 기본 토분 색상 지정은 철회했습니다. 사용자가 고른 개별 화분 종류·색상은 유지합니다.
- 재배·정원·드래그·플로팅·분무·도감·뽑기 결과에서 같은 장미 외형을 사용합니다. 수집 도감은 총 157종입니다.
- 저장 v20은 신규 장미 씨앗 7종을 수량 0으로 추가하고 기존 ID·성장·재화·이력·화분 설정을 보존합니다. 이전 원문은 버전별 로컬 백업으로 보존하며 클라우드 복원도 같은 경로를 사용합니다.
- 같은 정원을 사용하는 PC는 모두 업데이트하세요. 기존 정원 저장 폴더는 유지합니다.

## 설치

- EXE: `MorningBloom-0.8.20-Windows-x64.zip` 전체 압축 해제 후 `MorningBloom.exe` 실행.
- BAT: `MorningBloom-0.8.20-Python-BAT.zip` 전체 압축 해제 후 `run-python.bat` 실행. Python 3.12 64비트가 필요합니다.
- 기존 런처의 업데이트 기능도 사용할 수 있습니다.
