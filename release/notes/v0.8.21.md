# Morning Bloom v0.8.21

## 화분 팔레트 32색

- 뉴트럴·어스톤·파스텔·딥 계열 각 8색, 총 32색을 추가했습니다. 확인한 팔레트의 HEX 값을 그대로 반영했습니다.
- `화분 꾸미기 → 색상`에서 카테고리별 실제 색상칩을 선택하고 이름·HEX·식물/화분 미리보기를 확인할 수 있습니다.
- 테라코타·세이지 그린·크림 베이지·클레이 핑크·올리브 그린·라벤더를 추천색으로 제공합니다.
- 기존 기본·베이지·차콜·버건디·아이보리·세이지·더스티 블루 7개는 `이전 색상`에서 유지합니다. 이전에 저장한 색상을 새 팔레트로 자동 변경하지 않습니다.

## HEX·컬러 피커와 적용 흐름

- `#RRGGBB` 또는 `RRGGBB` 형식의 HEX를 입력하거나 컬러 피커에서 사용자 색상을 고를 수 있습니다. 불완전하거나 잘못된 HEX는 적용을 막고 안내합니다.
- 색상 화면의 `이 색상 사용`은 바깥 화분 선택 화면에 반영합니다. `이 화분에 담기`를 눌러 해당 식물·슬롯에 최종 저장합니다.
- 색상 선택·컬러 피커·화분 선택을 취소하면 기존 선택과 실제 정원 설정을 유지합니다. 저장 실패 시 기존 설정을 복구하고 선택 화면을 유지합니다.
- 같은 종류의 화분도 식물마다 다른 색상으로 사용할 수 있으며 씨앗·재화·성장 진행은 유지합니다.
- 320px·520px 창에서 색상칩과 사용자 입력을 스크롤할 수 있고 적용·취소 버튼은 하단에 유지합니다.

## 토분 질감과 저장 호환

- 기본 토분 본체에 고정된 미세 입자 질감을 적용했습니다. 프레임마다 입자가 바뀌지 않으며 게임 난수를 소비하지 않습니다.
- 다른 화분의 무늬·재질과 꽃잎 영역을 유지합니다. 재배·정원·드래그·보관 목록·플로팅·분무 화면이 같은 색상과 렌더러를 사용합니다.
- 저장 v21은 새로운 색상 ID와 사용자 RGB를 지원합니다. v20 저장은 기존 값과 필드를 보존하고 스키마만 이전합니다. 로컬 원문 백업·클라우드 복원도 검증했습니다.
- 같은 정원을 사용하는 PC는 모두 업데이트하세요. 기존 정원 저장 폴더는 유지합니다.

## 설치

- EXE: `MorningBloom-0.8.21-Windows-x64.zip` 전체 압축 해제 후 `MorningBloom.exe` 실행.
- BAT: `MorningBloom-0.8.21-Python-BAT.zip` 전체 압축 해제 후 `run-python.bat` 실행. Python 3.12 64비트가 필요합니다.
- 기존 런처의 업데이트 기능도 사용할 수 있습니다.

반영: #29, PR #30. 전체 32색과 실제 선택 화면은 `docs/pot-color-palette.ko.md`에 기록했습니다.
